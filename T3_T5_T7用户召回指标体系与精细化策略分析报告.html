T3 / T5 / T7 用户召回指标体系与精细化策略分析

本体系把“是否进入 App”与“是否值得用降息券”拆开判断：活跃说明存在接触机会，提单页、方案比较和确认行为说明需求与决策进度；只有处在决策犹豫区间的用户才进入降息券实验。目标是提升增量净利润，而非向所有可能提单的用户让利。

三、五类用户标签与具体召回策略

标签按优先级覆盖：从最接近成交的人群向低需求人群依次判断，避免用户同时落入多类策略。

S1 · 强自然转化

不发券，保护收益

第一阶段活跃，且满足：newconfirm>0；或 contract_newdetails>0；或 newpage≥4 且方案比较指数≥2；或 apply_duration≥120 秒且方案比较指数≥2。

  • 动作：额度、期限、流程提醒；不做价格让利。
  • 触达：第二阶段开始日一次提醒。
  • 目的：避免补贴本来就会提单的用户。
S2 · 价格犹豫型

降息券实验主目标

第一阶段活跃，newpage=1–3、newconfirm=0、apply_duration=31–120 秒，且方案比较指数为 1–2。

  • 动作：小额、短有效期降息券。
  • 触达：第二阶段开始日，或再次进入提单页 30–60 分钟内。
  • 约束：必须保留不发券对照组。
S3 · 期限犹豫型

先推期次方案

term_selection≥2 且 plan_newdetails>0，但金额切换弱、未确认提单。

  • 动作：推荐更合适期次、展示月供差异。
  • 触达：期次组合卡片或月供测算页。
  • 券策略：对“方案引导无响应”者再测试定向券。
S4 · 金额犹豫型

先推金额方案

amount_selection≥2、newpage>0、newconfirm=0，且期限切换不显著。

  • 动作：低月供金额、常用金额、额度解释。
  • 触达：金额调整建议与月供预估。
  • 券策略：金额方案无响应后，再进入小流量券实验。
S5 · 低意愿 / 泛浏览

默认不发券

无 active_date；或 active_duration 有值但 apply_duration=0、newpage=0、方案比较指数=0。

  • 动作：低频额度提醒、首页入口优化。
  • 触达：不高频、不连续加码。
  • 转化规则：后续进入提单页才重新打标。

发现 1：中意愿是优先实验样本

T3/T5/T7 中意愿用户提单率分别为 69.01%、64.83%、58.79%，比强意愿低 10.88、11.12、12.68 个百分点；同时占比约 27%–29%，兼具可撬动空间和足够的样本量。

发现 2：低意愿并不等于不提单

低意愿人群提单率仍为 49.11%–60.71%，说明其中存在自然需求用户。普惠发券会把这部分自然转化变成低收益订单，因此应先等待新的提单页或方案比较信号。

发券触发

仅 S2 默认进入券实验；S3、S4 先做方案引导，未转化且再次进入提单页后才进入实验池。

频控规则

每个用户、每个结清事件最多一次券实验；避免同一用户多笔结清事件在同一周期叠加优惠。

实验必看指标

提单增量率、放款额、券成本、收入、逾期率、双逾期率、单用户增量净利润。

六、结论与边界

可立即落地

以 S1–S5 标签替代“所有活跃用户统一发券”。强意愿不发券；价格犹豫型进入 A/B 实验；期限和金额犹豫型先匹配方案；低意愿不发券。

必须通过实验验证

行为指标反映的是需求和决策进度，不等同于价格敏感。降息券是否真正带来增量提单、增量放款和正向净利润，必须用随机对照验证。

建议补齐 experiment_id、分层标签、coupon_id、券面额、发放/领取/使用时间、提单、放款、收入、券成本、逾期与信用损失字段，才可持续优化每个标签的券策略。

附录：核心标签计算公式
活跃：第一阶段 COUNT(DISTINCT active_date) > 0

方案比较指数 =
  CASE WHEN amount_selection > 0 THEN 1 ELSE 0 END
+ CASE WHEN term_selection > 0 THEN 1 ELSE 0 END
+ CASE WHEN plan_newdetails > 0 THEN 1 ELSE 0 END

S1 强自然转化：
  active_day_cnt > 0
  AND (
       newconfirm > 0
       OR contract_newdetails > 0
       OR (newpage >= 4 AND 方案比较指数 >= 2)
       OR (apply_duration >= 120 AND 方案比较指数 >= 2)
  )

S2 价格犹豫型：
  active_day_cnt > 0
  AND newpage BETWEEN 1 AND 3
  AND newconfirm = 0
  AND apply_duration BETWEEN 31 AND 120
  AND 方案比较指数 BETWEEN 1 AND 2

S3 期限犹豫型：term_selection >= 2 AND plan_newdetails > 0
S4 金额犹豫型：amount_selection >= 2 AND newpage > 0 AND newconfirm = 0
S5 低意愿：active_day_cnt = 0；或 apply_duration = 0、newpage = 0、方案比较指数 = 0
