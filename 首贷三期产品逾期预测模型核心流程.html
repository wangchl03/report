一、项目背景与数据范围

1.1 业务场景

首贷用户完成3期借款后，在第2期到期时预测是否最终逾期。逾期 = loan_status_code=8。v6 移除 t2_ovd 和 t2_ahead（第2期逾期天数和提前还款天数），因为这两个特征在预测时点不可知（属于后验特征），使用它们会导致训练集高估AUC、生产环境预测偏差。

2.3 为什么必须移除 t2_ovd / t2_ahead？

v5 的 AUC 0.9780 存在虚假高估：t2_ovd 和 t2_ahead 是"已发生结果"而非"预测时已知特征"。训练时模型学会了 t2_ovd > 0 → 已逾期，但这在预测时点不可知。当用 v5 预测 300 名真实用户时（强制设 t2_ovd=0），平均预测概率 74.7%，实际逾期仅 8.7%——校准完全失效。v6 移除这两个特征后 AUC 降至 0.9609，但校准良好（2.6%→1.9%, 99%→99.8%）。

特征v5系数问题v6处理
t2_ovd+15.51（#1）预测时点第2期尚未逾期，值为0移除
t2_ahead-1.15（#5）预测时点第2期尚未还款，值为0移除
t1_ovd+11.18（#1）第1期已完成，特征值已知可用保留

三、算法原理

Sigmoid + 交叉熵 + liblinear求解器。C=0.5（中等正则化）。标准化后训练，系数可直接比较。v5 沿用 v4 算法框架，仅在特征层面扩展循环贷与优惠券维度。

P(逾期) = 1 / (1 + e^(-z)), z = w₀ + Σwᵢ·xᵢ'

五、特征解读

5.1 t1_ovd 是 v6 最强预测因子（系数 +11.18）

v5 中 t1_ovd 和 t2_ovd 并列第一（+13.79/+15.51），但 t2_ovd 是后验特征——模型在第2期逾期发生后才拿到的"作弊答案"。v6 移除 t2_ovd 后，t1_ovd 独自承担逾期风险识别任务（系数 +11.18）。第1期逾期天数每增加 1 个标准差，逾期概率暴涨数十倍。这是 v6 在预测时点最强的可用信号。

5.2 np(newpage) 仍是核心保护因子（系数 -2.77）

进入提单页次数多说明用户在主动规划下一笔借款，而非被动缺钱。v6 中 np 的权重（-2.77）甚至高于 v5（-2.23），因为移除 t2_ovd 后模型对数特征的依赖加深了。

5.3 优惠券特征信号增强（cp+0.51, cc+0.50, c2_cnt-0.34）

v5 中优惠券特征层次感不强，v6 移除 t2_ovd 后优惠券信号被释放：cp(coupons_page) 和 cc(coupons_confirm) 正向系数说明频繁查看/点击优惠券的用户是"犹豫型"——对价格敏感，逾期风险略高。而 c2_cnt（还款券个数）负向系数说明使用还款券的用户还款意愿更强。优惠券是行为信号而非结果信号。

6.2 决策规则 (v6)

  1. t1_ovd > 3 → 拒绝（第1期逾期天数严重）
  2. t1_ovd=0 + ad≥3 + np≥2 → 极低
  3. cp+cc 高 + cf 低 → 加一档（犹豫型用户）
  4. c2_cnt≥1 + t1_ovd=0 → 降一档（还款券+无逾期=黏性信号）
  5. apply_amt_k 高 + np 低 → 加一档（大额+无规划）
