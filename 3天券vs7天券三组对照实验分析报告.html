六、3天券 vs 7天券 差异画像（结论）

01

7 天券的额外价值集中在「慢决策成熟用户」。

B 组增量最大的层：活跃 1~2 天（+8.86/+8.89pp）、借款 3 次（+8.39pp）、历史提单 3 次（+13.44pp）、上笔 2 期（+9.83pp）、high rate（+6.72pp）、高金额≥8000（+6.60pp）。共同画像：有明确需求但需要更长比较/决策窗口。

02

3 天券的独特价值在「沉默用户的临期刺激」。

沉默用户（活跃0天）：3 天券 +4.86pp（C组）明显高于 7 天券 +0.19pp（A组）——沉默用户对「临期紧迫感」有响应，给宽裕的 7 天反而无感。7 天券对沉默用户甚至为负（B组 -1.18pp）。

03

有逾期用户：两种券都几乎无效。

A +1.29pp / B +1.26pp / C +0.10pp，三个口径都极低——逾期用户对降息券不敏感，不建议作为券投放对象。

04

券期内两种券等价，差异只在券期后。

B 组前 3 天 +0.39pp（等价），第 4~5 天 +2.98pp（7天券承接）。所以「该发 3 天还是 7 天」本质是「用户决策周期多长」的问题。

七、运营建议

A

活跃 + 成熟 + 高价值用户 → 发 7 天券。

这类用户（活跃1~2天、借款/提单3次、high rate、高金额、2期）需要更长的决策窗口，7 天券的第 4~5 天承接价值能带来额外 +6~13pp 增量。

B

沉默 / 低意向用户 → 发 3 天券（或不发）。

沉默用户靠 3 天券的临期紧迫感拉动（+4.86pp），7 天券对其无效；但沉默用户整体转化率低，可先低成本唤醒再决定是否给券。

C

有逾期用户 → 不建议发降息券。

三个口径都显示券增量约 +0.1~1.3pp，投入产出比极低，应改用其他风控/运营手段。

D

券期限作为分层变量，而非全局统一。

3 天券和 7 天券覆盖的是不同决策周期的人群，建议按「第一阶段活跃度 + 借款深度 + 利率类型」分层后差异化匹配券期限。

口径说明：券增量 = 实验组 − 对照组首次提单率（召回日起 7 天内）。A 组（0716~0719）7天券 vs 无券；B 组（0730~0807）7天券 vs 3天券；C 组（0813~0823）3天券 vs 无券。第一阶段 = 结清后至触达前 4 天空窗期，活跃度用宽表 active_days_cnt 字段（已验证与 event_track 口径一致）。A、C 组为跨批次对比，绝对数值含批次因素；券期限的纯差异以 B 组为准。
