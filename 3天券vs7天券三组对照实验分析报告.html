四·附、10 个维度的逐维分析

以下逐维度解读「3天券 vs 7天券」的差异及适配人群。数据为前 7 天累计券增量（A=7天券vs无券，B=7天券vs3天券，C=3天券vs无券）。

1

第一阶段活跃天数——券期限选择的第一变量。

沉默用户（0天）3天券 +4.86pp 明显高于 7天券 +0.19pp，7天券对沉默用户甚至为负（B组 -1.18pp）；而活跃 1~2 天用户 7天券（+8.89/+17.76pp）大幅强于 3天券（-6.17/+6.49pp）。结论：沉默用户发 3 天券（靠临期紧迫感），活跃用户发 7 天券（给足决策窗口）。

2

高息率——高息用户两种券都敏感，无高息只有 7 天券有效。

高高息(>0.5) 用户两种券都强（7天券 +11.28pp / 3天券 +7.89pp）；无高息(0) 用户 3天券几乎无效（-0.05pp）、7天券有效（+8.82pp）；低高息(0~0.5] 用户 7天券额外价值最大（B组 +6.17pp）。结论：高息用户随便发哪种都行，无高息/低高息用户应发 7 天券。

3

历史放款次数——新手和 3 次用户发 7 天券，4 次+ 谨慎。

新手(1次) 7天券 +8.56pp 强于 3天券 +3.17pp；3次用户 7天券额外价值大（B组 +8.39pp）；4次+ 用户 3天券为负（-1.36pp）、7天券额外价值也为负（-0.72pp）。结论：1~3 次借款用户发 7 天券；4 次以上老用户对券已钝化，不建议发券。

4

有无逾期——有逾期用户两种券都无效。

无逾期用户 7天券 +9.36pp 强于 3天券 +2.08pp；有逾期用户三个口径都极低（A +1.29 / B +1.26 / C +0.10pp）。结论：有逾期用户不建议发降息券，改用风控/还款提醒等其他手段。

5

上笔期数——2 期用户是 7 天券核心受众。

2期用户 7天券额外价值最大（B组 +9.83pp）；1期用户 7天券反而为负（-11.93pp，样本仅 61/54 人需谨慎）；3、4期用户 7天券略强。两期产品通常对应 7 天还款节奏，用户决策窗口更长。结论：2 期（及 3、4 期）用户发 7 天券。

6

上笔利率类型——high rate 用户发 7 天券。

high rate 用户 7天券额外价值 +6.72pp（A +6.86 / C +4.33）；low rate 用户两种券差异小（B组仅 +1.19pp）。结论：high rate（高息定价）用户发 7 天券能吃到更大增量。

7

历史放款金额——高金额用户两种券都强，中金额只认 7 天券。

高金额(≥8000) 用户两种券都强（7天券 +10.32 / 3天券 +7.46pp）；中金额(3000~8000) 用户 3天券为负（-4.98pp）、7天券为正（+2.57pp）；低金额 7天券更强（+8.31 vs +2.01pp）。结论：高金额用户随便发，中低金额用户发 7 天券。

8

历史提单次数——3 次提单用户是 7 天券最大受益者。

3次提单用户 7天券额外价值 +13.44pp（全场最高），但 3天券对其仅 +0.73pp；1次用户 7天券 +9.36pp 强于 3天券 +2.41pp。结论：提单 1~3 次的用户发 7 天券，尤其 3 次提单的成熟用户。

9

额度使用率——中等使用率用户 7 天券额外价值更大。

中(50~90%) 用户 7天券额外价值 +5.86pp（A +9.40 / C +0.98）；高(≥90%) 用户差异较小（B组 +1.77pp）。结论：额度使用率中等的用户是 7 天券的增量来源，使用率已打满的用户两种券差异不大。

10

上笔逾期天数——上笔无逾期用户发 7 天券。

上笔无逾期(<0) 用户 7天券 +9.37pp 明显强于 3天券 +1.92pp；上笔有逾期(≥0) 用户整体增量都偏低（最高仅 +4.70pp）。结论：上笔无逾期（优质履约）用户发 7 天券，有逾期记录用户不建议发券。

六、3天券 vs 7天券 差异画像（结论）

01

7 天券的额外价值集中在「慢决策成熟用户」。

B 组增量最大的层：活跃 1~2 天（+8.86/+8.89pp）、借款 3 次（+8.39pp）、历史提单 3 次（+13.44pp）、上笔 2 期（+9.83pp）、high rate（+6.72pp）、高金额≥8000（+6.60pp）。共同画像：有明确需求但需要更长比较/决策窗口。

02

3 天券的独特价值在「沉默用户的临期刺激」。

沉默用户（活跃0天）：3 天券 +4.86pp（C组）明显高于 7 天券 +0.19pp（A组）——沉默用户对「临期紧迫感」有响应，给宽裕的 7 天反而无感。7 天券对沉默用户甚至为负（B组 -1.18pp）。

03

有逾期用户：两种券都几乎无效。

A +1.29pp / B +1.26pp / C +0.10pp，三个口径都极低——逾期用户对降息券不敏感，不建议作为券投放对象。

04

券期内两种券等价，差异只在券期后。

B 组前 3 天 +0.39pp（等价），第 4~5 天 +2.98pp（7天券承接）。所以「该发 3 天还是 7 天」本质是「用户决策周期多长」的问题。

七、运营建议

A

活跃 + 成熟 + 高价值用户 → 发 7 天券。

这类用户（活跃1~2天、借款/提单3次、high rate、高金额、2期）需要更长的决策窗口，7 天券的第 4~5 天承接价值能带来额外 +6~13pp 增量。

B

沉默 / 低意向用户 → 发 3 天券（或不发）。

沉默用户靠 3 天券的临期紧迫感拉动（+4.86pp），7 天券对其无效；但沉默用户整体转化率低，可先低成本唤醒再决定是否给券。

C

有逾期用户 → 不建议发降息券。

三个口径都显示券增量约 +0.1~1.3pp，投入产出比极低，应改用其他风控/运营手段。

D

券期限作为分层变量，而非全局统一。

3 天券和 7 天券覆盖的是不同决策周期的人群，建议按「第一阶段活跃度 + 借款深度 + 利率类型」分层后差异化匹配券期限。

  ROUND(AVG(CASE WHEN ab_group='control'   THEN applied3 END)::numeric*100, 2) AS 对照组前3天,
  ROUND((AVG(CASE WHEN ab_group='treatment' THEN applied3 END)
       - AVG(CASE WHEN ab_group='control' THEN applied3 END))::numeric*100, 2) AS 前3天增量pp,
  ROUND(AVG(CASE WHEN ab_group='treatment' THEN applied7 END)::numeric*100, 2) AS 实验组前7天,
  ROUND(AVG(CASE WHEN ab_group='control'   THEN applied7 END)::numeric*100, 2) AS 对照组前7天,
  ROUND((AVG(CASE WHEN ab_group='treatment' THEN applied7 END)
       - AVG(CASE WHEN ab_group='control' THEN applied7 END))::numeric*100, 2) AS 前7天增量pp
FROM tmp_coupon_exp
GROUP BY grp
ORDER BY grp;
模块三：逐日券增量（D1~D7）
-- ============================================================
-- 模块三：逐日券增量（第1~7天，D1=召回日当天）
-- ============================================================
WITH day_cnt AS (
  SELECT grp, ab_group, day_idx, COUNT(*) AS cnt
  FROM tmp_coupon_exp
  WHERE day_idx IS NOT NULL
  GROUP BY grp, ab_group, day_idx
),
tot AS (
  SELECT grp, ab_group, COUNT(*) AS n FROM tmp_coupon_exp GROUP BY grp, ab_group
)
SELECT d.grp AS 组, 'D' || (d.day_idx + 1) AS 第几天,
  ROUND((MAX(CASE WHEN d.ab_group='treatment' THEN d.cnt * 100.0 / t.n END)
       - MAX(CASE WHEN d.ab_group='control'   THEN d.cnt * 100.0 / t.n END)), 2) AS 逐日增量pp
FROM day_cnt d
JOIN tot t ON t.grp = d.grp AND t.ab_group = d.ab_group
GROUP BY d.grp, d.day_idx
ORDER BY d.grp, d.day_idx;
模块四：10 个维度特征分层 × 券增量
-- ============================================================
-- 模块四：10 个维度特征分层 × 券增量（前7天口径）
-- 用 UNION ALL 统一 10 个维度为 (dim, seg)，再按组计算券增量
-- ============================================================
WITH seg AS (
  SELECT grp, ab_group, applied7, '活跃天数' AS dim,
         CASE WHEN active_days_cnt<=0 THEN '0天' WHEN active_days_cnt=1 THEN '1天' WHEN active_days_cnt=2 THEN '2天' WHEN active_days_cnt=3 THEN '3天' ELSE '4天' END AS seg
  FROM tmp_coupon_exp
  UNION ALL SELECT grp, ab_group, applied7, '高息率', CASE WHEN high_interest_rate<=0 THEN '无高息(0)' WHEN high_interest_rate<=0.5 THEN '低高息(0~0.5]' ELSE '高高息(>0.5)' END FROM tmp_coupon_exp
  UNION ALL SELECT grp, ab_group, applied7, '放款次数', CASE WHEN total_remit_rnb<=1 THEN '1次' WHEN total_remit_rnb=2 THEN '2次' WHEN total_remit_rnb=3 THEN '3次' ELSE '4次+' END FROM tmp_coupon_exp
  UNION ALL SELECT grp, ab_group, applied7, '有无逾期', CASE WHEN overdue_cnt>0 THEN '有逾期' ELSE '无逾期' END FROM tmp_coupon_exp
  UNION ALL SELECT grp, ab_group, applied7, '上笔期数', last_remit_total_term::int::text || '期' FROM tmp_coupon_exp
  UNION ALL SELECT grp, ab_group, applied7, '利率类型', last_remit_interest_type FROM tmp_coupon_exp
  UNION ALL SELECT grp, ab_group, applied7, '放款金额', CASE WHEN total_remit_amt<3000 THEN '低(<3000)' WHEN total_remit_amt<8000 THEN '中(3000~8000)' ELSE '高(>=8000)' END FROM tmp_coupon_exp
  UNION ALL SELECT grp, ab_group, applied7, '提单次数', CASE WHEN total_apply_rnb<=1 THEN '1次' WHEN total_apply_rnb=2 THEN '2次' WHEN total_apply_rnb=3 THEN '3次' ELSE '4次+' END FROM tmp_coupon_exp
  UNION ALL SELECT grp, ab_group, applied7, '额度使用率', CASE WHEN utilization_rate<0.9 THEN '中(50~90%)' ELSE '高(>=90%)' END FROM tmp_coupon_exp
  UNION ALL SELECT grp, ab_group, applied7, '上笔逾期天数', CASE WHEN last_remit_overdue_days<0 THEN '无逾期(<0)' ELSE '有逾期(>=0)' END FROM tmp_coupon_exp
)
SELECT dim AS 维度, seg AS 分段, grp AS 组,
  SUM(CASE WHEN ab_group='treatment' THEN 1 ELSE 0 END) AS 实验组n,
  ROUND(AVG(CASE WHEN ab_group='treatment' THEN applied7 END)::numeric*100, 2) AS 实验组提单率,
  SUM(CASE WHEN ab_group='control' THEN 1 ELSE 0 END) AS 对照组n,
  ROUND(AVG(CASE WHEN ab_group='control' THEN applied7 END)::numeric*100, 2) AS 对照组提单率,
  ROUND((AVG(CASE WHEN ab_group='treatment' THEN applied7 END)
       - AVG(CASE WHEN ab_group='control' THEN applied7 END))::numeric*100, 2) AS 券增量pp
FROM seg
GROUP BY dim, seg, grp
ORDER BY dim, seg, grp;

口径说明：券增量 = 实验组 − 对照组首次提单率（召回日起 7 天内）。A 组（0716~0719）7天券 vs 无券；B 组（0730~0807）7天券 vs 3天券；C 组（0813~0823）3天券 vs 无券。第一阶段 = 结清后至触达前 4 天空窗期，活跃度用宽表 active_days_cnt 字段（已验证与 event_track 口径一致）。A、C 组为跨批次对比，绝对数值含批次因素；券期限的纯差异以 B 组为准。
