项目固定定义
预测对象用户×严格T0获额通过事件；event_id取保留的credit_serial_id。一个用户可有多次T0，不把所有事件压成一行。

去重优先级同用户同serial先取最新获额；相邻通过记录时间差≤20秒合成链式批次，保留获额时间最大、同时间serial_id最大记录。不是每20秒固定切片，也不是同日只留一次。

五、特征工程规则与统一算子

算子 / 命名精确规则使用注意
valid_n / mean / std / min / max只对有效非缺失值计算；std采用总体标准差ddof=0。无有效值：valid_n=0，统计量NaN；一个有效值的std=0。
l1…l5 / delta12 / delta23按已定义时间顺序取原序列最近第k笔；差值为最近1−2、2−3。不跳过缺失去找“最近第k个有效值”；历史不足为NaN。
last3_mean / last5_mean原序列最近3/5笔内有效值均值。不足3/5笔可按已有有效值求均值；记录有效样本数辅助判断。
last_first_delta / slope最近−最早有效值；斜率按原生命周期顺序序号做一元最小二乘。不是每个自然日的变化速度；有效值<2时缺失。
recent_lifetime_delta最近3笔有效均值−全历史有效均值。反映近期偏离，不代表额度/提前还款产生因果影响。
n / share满足条件次数；满足次数/有效值数量。share不是/全部订单数；零分母为NaN。≥3/7/10阈值存在嵌套，不能相加。
current_streak / max_streak最近向前连续次数 / 历史最长连续次数。不满足和缺失均中断；缺失不能跳过后拼接连续。
App原计数 / 日均 / 次数比逐窗口埋点加总；日均按eligible_days；amount/plan/confirm_per_newpage是埋点次数比。不是用户占比；可>1。确认埋点不等于订单表提单成功。
近期变化近7日−前7日；近7日/前7日；近3日每可观察日−近14日每可观察日。前窗无记录先累加0；早期历史不足不是已经观察了完整前7日。
存储与筛除全部新增列存float32；NaN原生交给LightGBM。只用训练风险行判断常量/全缺失。计数也是float32物理存储，超大整数精度需上线另验；类别映射在训练集冻结，未知类别映射NaN。

额度使用率

历史实际提单金额÷同订单提单前最新通过获额额度。≤0按缺失；>100%有效。当前获额未提单，占用未知，不构造当前使用率。

变额及费用容差

变额=当前获额−触发结清订单获额。金额/比例分档均为绝对值，方向另存。日息绝对差<0.05pp、息费绝对差<1pp记不变；等于阈值计变化。

真实流水结清

已整笔结清的同订单支付中，取结清时刻前最后实际支付；其自然日需与整笔结清日一致。失配置NaN，不直接回填订单结清日。提前天数=到期日−核验实际结清日，可为负。

页面时长

event_start/end按毫秒计算秒数；仅page_view_out、end≥start且end≤截断时点，每条上限3,600秒。只加已结束页面，不加未来才结束区间；重叠未去重，不等于真实独占活跃时长。

缺失≠零

无有效历史、零分母、核验失败→NaN；有可观察日期但没有某行为→0。交互标记在历史不足时可能为0，必须与valid_n/缺失字段一起解读。

非还款日不是页面过滤

任意订单实际支付发生的自然日，整天从nonpay分支删除。没有可观察非还款日→行为量NaN；不能解释为用户零活跃。

    for label,condition in conditions.items():
        flag=condition(values)&np.isfinite(values)
        out[prefix+'_'+label+'_n']=int(flag.sum())
        out[prefix+'_'+label+'_share']=safe(flag.sum(),n)
        out[prefix+'_'+label+'_current_streak']=current_streak(flag)
        out[prefix+'_'+label+'_max_streak']=maximum_streak(flag)

def parse_times(df,cols):
    for c in cols:df[c]=pd.to_datetime(df[c],format='mixed',errors='coerce')
    return df

def load_histories():
    orders=pd.read_csv(ROOT/'sources/orders.csv.gz',dtype={'product_no':str,'loan_type':str})
    parse_times(orders,['reg_date','apply_time','apply_date','remit_time','remit_date','repaid_time','repaid_date','due_date'])
    orders=orders.sort_values(['user_id','apply_time','serial_id']).reset_index(drop=True)
    assert not orders.duplicated(['user_id','serial_id']).any()
    assert not orders.serial_id.duplicated().any(),'Serial IDs must be globally unique for source paging'
    credits=pd.read_csv(ROOT/'sources/credits.csv.gz');parse_times(credits,['credit_time'])
    credits=credits.sort_values(['user_id','credit_time','serial_id']).reset_index(drop=True)
    payments=pd.read_csv(ROOT/'sources/payments.csv.gz');parse_times(payments,['payin_date'])
    unix=pd.to_numeric(payments.payin_time,errors='coerce');seconds=unix.where(unix<10**11,unix/1000)
    payments['payment_time']=pd.to_datetime(seconds,unit='s',utc=True,errors='coerce').dt.tz_convert('America/Belize').dt.tz_localize(None)
    payments['timestamp_valid']=(payments.payment_time.dt.normalize()==payments.payin_date)&(seconds>946684800)
    # Invalid/inconsistent intraday timestamps do not silently become midnight events.
    payment_audit={'ledger_rows':len(payments),'source_rows':int(payments.source_rows.sum()),
                   'invalid_time_n':int((~payments.timestamp_valid).sum()),'timestamp_unit':'seconds; millisecond values normalized',
                   'definition':'positive posted repayment_record_copy, not a separate payment success flag'}
    payments=payments.sort_values(['user_id','payment_time','serial_id']).reset_index(drop=True)
    approved=credits.loc[credits.is_pass1.eq(1),['user_id','serial_id','credit_time','credit_amt']].sort_values('credit_time')
    joined=pd.merge_asof(orders[['user_id','serial_id','apply_time']].assign(original_row=np.arange(len(orders))).sort_values('apply_time'),
                         approved,left_on='apply_time',right_on='credit_time',by=['user_id','serial_id'],direction='backward')
    orders['credit_amt']=joined.sort_values('original_row').credit_amt.to_numpy()
    orders['utilization']=(orders.apply_amt/orders.credit_amt.where(orders.credit_amt>0)).where(orders.apply_amt>0)
    orders['fee_rate']=(orders.pre_amt+orders.post_amt)/orders.remit_amt.where(orders.remit_amt>0)
    orders['daily_rate']=orders.fee_rate/orders.loan_day.where(orders.loan_day>0)
    known=orders.loc[orders.repaid_time.gt(pd.Timestamp('2000-01-01'))&((orders.is_repaid==1)|(orders.loan_status_code==7)),['user_id','serial_id','repaid_time','repaid_date']]
    ledger=payments.loc[payments.timestamp_valid].merge(known,on=['user_id','serial_id'],how='inner',validate='many_to_one')
    ledger=ledger.loc[ledger.payment_time.le(ledger.repaid_time)]
    aggregate=ledger.groupby('serial_id').agg(flow_settle_time=('payment_time','max'),settle_cash=('amount','sum'),
               settle_payment_n=('source_rows','sum'),settle_payment_days=('payin_date','nunique'))
    orders=orders.merge(aggregate,left_on='serial_id',right_index=True,how='left',validate='one_to_one')
    bad=orders.flow_settle_time.dt.normalize().ne(orders.repaid_date)
    orders.loc[bad,'flow_settle_time']=pd.NaT
    orders.loc[bad,['settle_cash','settle_payment_n','settle_payment_days']]=np.nan
    orders['early_days']=(orders.due_date-orders.flow_settle_time.dt.normalize()).dt.days
    orders['apply_settle_days']=(orders.flow_settle_time-orders.apply_time).dt.total_seconds()/86400
    orders['remit_settle_days']=(orders.flow_settle_time-orders.remit_time).dt.total_seconds()/86400
    orders['settle_cash_remit_ratio']=orders.settle_cash/orders.remit_amt.where(orders.remit_amt>0)
    orders.to_pickle(ROOT/'datasets/order_lifecycle_enriched.pkl.gz',compression='gzip')
    payment_audit['settled_orders_with_verified_cash_day']=int(orders.flow_settle_time.notna().sum())
    payment_audit['settled_orders_total']=int(((orders.is_repaid==1)|(orders.loan_status_code==7)).sum())
    (ROOT/'analysis/payment_source_audit.json').write_text(json.dumps(payment_audit,ensure_ascii=False,indent=2))
    return orders,credits,payments,None

def loan_features(orders,payments,credits,t,settled_serial,current,previous):
    out={}; hist=orders.loc[orders.apply_time<t]
    funded=hist.loc[hist.is_remit.eq(1)&hist.remit_amt.gt(0)&hist.remit_time.le(t)].sort_values(['remit_time','serial_id'])
    closed=funded.loc[((funded.is_repaid==1)|(funded.loan_status_code==7))&funded.repaid_time.gt(pd.Timestamp('2000-01-01'))&funded.repaid_time.le(t)].sort_values(['repaid_time','serial_id'])
    verified=closed.loc[closed.flow_settle_time.notna()]
    trigger=closed.loc[closed.serial_id.eq(settled_serial)]
    out.update(life_apply_n=len(hist),life_funded_n=len(funded),life_closed_n=len(closed),life_verified_closed_n=len(verified),
               life_flow_closed_missing_share=safe(len(closed)-len(verified),len(closed)),
               life_funding_rate=safe(len(funded),len(hist)),life_closed_rate=safe(len(closed),len(funded)))
    trigger_rnb=trigger.remit_succ_rnb.iloc[-1] if len(trigger) and 'remit_succ_rnb' in trigger else np.nan
    out['trigger_successful_remit_rnb']=float(trigger_rnb) if pd.notna(trigger_rnb) and trigger_rnb>0 else np.nan
    out['trigger_rnb_vs_life_count']=out['trigger_successful_remit_rnb']-len(funded)
    out['trigger_is_latest_funded_order']=int(len(funded)>0 and funded.serial_id.iloc[-1]==settled_serial)
    if 'product_no' in funded:
        products=funded.product_no.dropna().astype(str).to_numpy();valid_product_n=len(products)
    else:products=np.asarray([],dtype=str);valid_product_n=0
    out['loan_product_valid_n']=valid_product_n;out['loan_product_distinct_n']=len(set(products))
    out['loan_product_switch_n']=int(np.sum(products[1:]!=products[:-1])) if len(products)>1 else 0
    out['loan_product_switch_share']=safe(out['loan_product_switch_n'],len(products)-1)
    out['loan_product_last5_distinct_n']=len(set(products[-5:]))
    for kind,g,col in [('apply',hist,'apply_time'),('funded',funded,'remit_time'),('closed',closed,'repaid_time')]:
        out['life_'+kind+'_age_days']=(t-g[col].min()).total_seconds()/86400 if len(g) else np.nan
        for w in [7,30,90,180]:out[f'life_{kind}_n_{w}d']=int(g[col].ge(t-pd.Timedelta(days=w)).sum())
    numeric=['apply_amt','remit_amt','credit_amt','utilization','fee_rate','daily_rate','loan_day','total_term']
    for col in numeric:describe(out,'loan_'+col,funded[col].to_numpy(),True)
    funded_credit=funded.credit_amt.to_numpy(float);funded_delta=np.diff(funded_credit)
    funded_ratio=np.divide(funded_delta,funded_credit[:-1],out=np.full(len(funded_delta),np.nan),where=funded_credit[:-1]>0)
    describe(out,'loan_credit_change',funded_delta,True);describe(out,'loan_credit_change_ratio',funded_ratio,True)
    rates(out,'loan_change',funded_delta,{'up':lambda x:x>0,'down':lambda x:x<0,'same':lambda x:x==0})
    for col in ['early_days','apply_settle_days','remit_settle_days','settle_payment_n','settle_payment_days','settle_cash_remit_ratio']:
        describe(out,'repay_'+col,closed[col].to_numpy(),True)
    early={ 'late':lambda x:x<0,'ontime':lambda x:x==0,'early_1_2':lambda x:(x>=1)&(x<3),
            'early_3_6':lambda x:(x>=3)&(x<7),'early_7_9':lambda x:(x>=7)&(x<10),
            'early_10_13':lambda x:(x>=10)&(x<14),'early_ge14':lambda x:x>=14}
    early.update({f'early_ge{k}':(lambda x,k=k:x>=k) for k in [3,7,10]})
    rates(out,'repay',closed.early_days,early)
    util={'low80':lambda x:x<.8,'80_99':lambda x:(x>=.8)&(x<.99),'99_100':lambda x:(x>=.99)&(x<=1),
          'over100':lambda x:x>1,'ge95':lambda x:x>=.95}
    rates(out,'util',funded.utilization,util)
    for col in ['apply_settle_days','remit_settle_days']:
        rates(out,col,closed[col],{f'le{k}':(lambda x,k=k:(x>=0)&(x<=k)) for k in [3,7,10,14]})
    for w in [30,90,180]:
        v=closed.loc[closed.repaid_time.ge(t-pd.Timedelta(days=w))]
        out[f'repay_early_share_{w}d']=safe(v.early_days.gt(0).sum(),v.early_days.notna().sum())
        out[f'repay_late_share_{w}d']=safe(v.early_days.lt(0).sum(),v.early_days.notna().sum())
        out[f'repay_early_days_mean_{w}d']=v.early_days.mean()
        f=funded.loc[funded.remit_time.ge(t-pd.Timedelta(days=w))]
        out[f'util_high_share_{w}d']=safe(f.utilization.ge(.95).sum(),f.utilization.notna().sum())
    early_values=closed.early_days.to_numpy(float)
    out['repay_ontime_to_early_n']=int(((early_values[:-1]==0)&(early_values[1:]>0)).sum()) if len(early_values)>1 else 0
    out['repay_early_to_late_n']=int(((early_values[:-1]>0)&(early_values[1:]<0)).sum()) if len(early_values)>1 else 0
    out['repay_late_to_early_n']=int(((early_values[:-1]<0)&(early_values[1:]>0)).sum()) if len(early_values)>1 else 0
    # Completed settlement-to-next-application cycles, unique nearest preceding settlement.
    gaps=[];calendar_gaps=[];settlearr=np.sort(closed.flow_settle_time.dropna().to_numpy('datetime64[ns]'))
    used=set()
    for at in hist.apply_time:
        k=np.searchsorted(settlearr,at.to_datetime64(),side='right')-1
        if k>=0 and k not in used:
            gaps.append((at.to_datetime64()-settlearr[k])/np.timedelta64(1,'D'))
            calendar_gaps.append((at.to_datetime64().astype('datetime64[D]')-settlearr[k].astype('datetime64[D]'))/np.timedelta64(1,'D'));used.add(k)
    describe(out,'reborrow_gap_days',gaps,True)
    rates(out,'reborrow',gaps,{f'le{k}':(lambda x,k=k:x<=k) for k in [0,3,7,10,14]})
    describe(out,'reborrow_calendar_gap_days',calendar_gaps,True)
    rates(out,'reborrow_calendar',calendar_gaps,{f'le{k}':(lambda x,k=k:x<=k) for k in [0,3,7,10,14]})
    out['reborrow_same_day_n']=sum(g==0 for g in calendar_gaps)
    out['reborrow_same_day_share']=safe(out['reborrow_same_day_n'],len(gaps))
    out['reborrow_completed_cycles']=len(gaps)
    out['reborrow_pending_closed_n']=max(0,len(settlearr)-len(used))
    out['reborrow_current_wait_days']=(t.to_datetime64()-settlearr[-1])/np.timedelta64(1,'D') if len(settlearr) else np.nan
    known_equal_serials=closed.loc[closed.repaid_time.eq(t),'serial_id']
    known_payment_cutoff=payments.payment_time.lt(t)|(payments.payment_time.eq(t)&payments.serial_id.isin(known_equal_serials))
    cash=payments.loc[payments.timestamp_valid&known_payment_cutoff]
    out['cash_total_rows']=cash.source_rows.sum();out['cash_total_days']=cash.payin_date.nunique()
    out['cash_total_amount']=cash.amount.sum();out['cash_order_n']=cash.serial_id.nunique()
    out['cash_days_since_first']=(t-cash.payment_time.min()).total_seconds()/86400 if len(cash) else np.nan
    out['cash_days_since_last']=(t-cash.payment_time.max()).total_seconds()/86400 if len(cash) else np.nan
    out['cash_rows_per_payment_day']=safe(out['cash_total_rows'],out['cash_total_days'])
    for w in [1,3,7,14,30,90,180]:
        g=cash.loc[cash.payment_time.ge(t-pd.Timedelta(days=w))]
        out[f'cash_rows_{w}d']=g.source_rows.sum();out[f'cash_days_{w}d']=g.payin_date.nunique();out[f'cash_amount_{w}d']=g.amount.sum()
    eligible=credits.loc[credits.credit_time.le(t)].drop_duplicates('serial_id',keep='last')
    all_passed=eligible.loc[eligible.is_pass1.eq(1)].sort_values(['credit_time','serial_id'])
    current_records=all_passed.credit_time.eq(t)
    out['offer_current_time_record_missing']=int(not current_records.any())
    if current_records.any():
        batch=(all_passed.credit_time.diff().gt(pd.Timedelta(seconds=20))|all_passed.credit_time.diff().isna()).cumsum()
        start=all_passed.loc[batch.eq(batch.iloc[-1]),'credit_time'].min()
        out['offer_current_batch_known_products_n']=int(batch.eq(batch.iloc[-1]).sum())
        # Earlier products in this same automatic batch are current conditions, not prior offer history.
        offer=eligible.loc[eligible.credit_time.lt(start)]
    else:
        out['offer_current_batch_known_products_n']=np.nan
        offer=eligible.loc[eligible.credit_time.lt(t)]
    out['offer_history_n']=len(offer);out['offer_history_pass_share']=safe(offer.is_pass1.eq(1).sum(),len(offer))
    passed=offer.loc[offer.is_pass1.eq(1)].sort_values(['credit_time','serial_id'])
    # Chain 20-second duplicate products; history features count episodes, not source rows.
    passed=passed.loc[~passed.credit_time.diff(-1).abs().le(pd.Timedelta(seconds=20))]
    describe(out,'offer_credit',passed.credit_amt.to_numpy(),True)
    changes=np.diff(passed.credit_amt.to_numpy(float))
    describe(out,'offer_credit_change',changes,True)
    past_credit=passed.credit_amt.to_numpy(float)
    relative_changes=np.divide(changes,past_credit[:-1],out=np.full(len(changes),np.nan),where=past_credit[:-1]>0)
    describe(out,'offer_credit_change_ratio',relative_changes,True)
    rates(out,'offer_change',changes,{'up':lambda x:x>0,'down':lambda x:x<0,'same':lambda x:x==0})
    out['offer_up_to_down_n']=int(((changes[:-1]>0)&(changes[1:]<0)).sum()) if len(changes)>1 else 0
    out['offer_down_to_up_n']=int(((changes[:-1]<0)&(changes[1:]>0)).sum()) if len(changes)>1 else 0
    # Demand proxies use previous realized demand, not future new-order utilization.
    trigger_apply=trigger.apply_amt.iloc[-1] if len(trigger) else np.nan
    out['demand_current_to_previous_apply']=safe(current,trigger_apply)
    out['demand_current_to_latest_attempt']=safe(current,hist.apply_amt.iloc[-1]) if len(hist) else np.nan
    out['demand_current_to_lifetime_apply']=safe(current,funded.apply_amt.mean())
    out['demand_current_to_max_apply']=safe(current,funded.apply_amt.max())
    out['demand_previous_apply_shortfall']=max(0,trigger_apply-current) if np.isfinite(trigger_apply) and np.isfinite(current) else np.nan
    out['demand_previous_util_missing']=int(not len(trigger) or pd.isna(trigger.utilization.iloc[-1]))
    last=trigger.utilization.iloc[-1] if len(trigger) else np.nan
    for k in [3,7,10,14]:
        out[f'interaction_early_ge{k}_short_reborrow']=int(len(verified)>0 and verified.early_days.iloc[-1]>=k and len(gaps)>0 and gaps[-1]<=3)
    for direction,label in [(-1,'down'),(0,'same'),(1,'up')]:
        flag=np.sign(current-previous)==direction
        out['interaction_'+label+'_high_util']=int(flag and np.isfinite(last) and last>=.95)
        out['interaction_'+label+'_over_util']=int(flag and np.isfinite(last) and last>1)
        out['interaction_'+label+'_first3']=int(flag and len(funded)<=3)
        out['interaction_'+label+'_first2']=int(flag and len(funded)<=2)
    out['trigger_early_days_cash']=trigger.early_days.iloc[-1] if len(trigger) else np.nan
    out['trigger_flow_time_missing']=int(not len(trigger) or pd.isna(trigger.flow_settle_time.iloc[-1]))
    return out

def behavior_features(daily,prefix,payments,t,reg,same_second_settled_serials=()):
    out={};day=t.normalize();hist=daily.loc[daily.create_date<day]
    # Only verified payment times determine repayment days; invalid timestamps remain an audited exclusion.
    known_payment_cutoff=payments.payment_time.lt(t)
    if same_second_settled_serials and 'serial_id' in payments:
        known_payment_cutoff=known_payment_cutoff|(payments.payment_time.eq(t)&payments.serial_id.isin(same_second_settled_serials))
    paid_dates=set(payments.loc[payments.timestamp_valid&known_payment_cutoff&payments.payin_date.lt(day),'payin_date'])
    if payments.loc[payments.timestamp_valid&known_payment_cutoff&payments.payin_date.eq(day)].shape[0]:paid_dates.add(day)
    if prefix is not None:
        dates=np.r_[hist.create_date.to_numpy('datetime64[ns]'),day.to_datetime64()]
        values=np.vstack([hist[BEH].to_numpy(float),[prefix[c] for c in BEH]])
        last_time=np.datetime64(prefix['last_active_time'],'ns') if pd.notna(prefix['last_active_time']) else np.datetime64('NaT','ns')
        last=np.r_[hist.last_active_time.to_numpy('datetime64[ns]'),last_time]
    else:
        dates=hist.create_date.to_numpy('datetime64[ns]');values=hist[BEH].to_numpy(float);last=hist.last_active_time.to_numpy('datetime64[ns]')
    observation_start=max(pd.Timestamp('2024-01-01'),reg) if pd.notna(reg) else pd.Timestamp('2024-01-01')
    out['app_history_left_censored']=int(pd.notna(reg) and reg<pd.Timestamp('2024-01-01'))
    out['app_history_observation_days']=max(0,(day-observation_start).days+1)
    active=(values[:,0]>0)&~np.isnat(last)
    out['app_days_since_last_active']=float((t.to_datetime64()-last[active].max())/np.timedelta64(1,'D')) if active.any() else np.nan
    repayflags=np.isin(dates,np.asarray(list(paid_dates),dtype='datetime64[ns]'))
    for branch in ['all','nonpay']:
        allowed=np.ones(len(dates),dtype=bool) if branch=='all' else ~repayflags
        for w in WINDOWS+['life']:
            start=observation_start if w=='life' else max(observation_start,day-pd.Timedelta(days=w-1))
            ix=allowed&(dates>=start.to_datetime64());sums=dict(zip(BEH,values[ix].sum(axis=0)));days=max(0,(day-start).days+1)
            excluded=sum(start<=d<=day for d in paid_dates) if branch=='nonpay' else 0
            eligible=max(0,days-excluded);pre=f'app_{branch}_{w}d_'
            out[pre+'eligible_days']=eligible;out[pre+'empty_eligible']=int(eligible==0)
            out[pre+'active_days']=int((values[ix,0]>0).sum())
            out[pre+'active_day_share']=safe(out[pre+'active_days'],eligible)
            for col in BEH:out[pre+col]=float(sums[col]) if eligible>0 else np.nan
            out[pre+'non_apply_duration']=float(sums['duration']-sums['apply_duration']) if eligible>0 else np.nan
            out[pre+'events_per_eligible_day']=safe(sums['events'],eligible)
            out[pre+'duration_per_active_day']=safe(sums['duration'],out[pre+'active_days'])
            out[pre+'apply_duration_share']=safe(sums['apply_duration'],sums['duration'])
            out[pre+'amount_per_newpage']=safe(sums['amount'],sums['newpage'])
            out[pre+'plan_per_newpage']=safe(sums['plan'],sums['newpage'])
            out[pre+'confirm_per_newpage']=safe(sums['confirm'],sums['newpage'])
            out[pre+'coupon_accept_share']=safe(sums['coupon_confirm'],sums['coupon_confirm']+sums['coupon_back'])
        prior_mask=allowed&(dates>=(day-pd.Timedelta(days=13)).to_datetime64())&(dates<(day-pd.Timedelta(days=6)).to_datetime64())
        prior=dict(zip(BEH,values[prior_mask].sum(axis=0)))
        for col in ['events','newpage','amount','plan','term','confirm','duration']:
            now=out[f'app_{branch}_7d_{col}'];before=prior[col]
            out[f'app_{branch}_{col}_7d_delta_prior7']=now-before
            out[f'app_{branch}_{col}_7d_ratio_prior7']=safe(now,before)
        for col in ['events','newpage','amount','plan','duration']:
            out[f'app_{branch}_{col}_3d_perday_vs14d']=safe(out[f'app_{branch}_3d_{col}'],out[f'app_{branch}_3d_eligible_days'])-safe(out[f'app_{branch}_14d_{col}'],out[f'app_{branch}_14d_eligible_days'])
    for w in [7,30,90]:
        for col in ['events','newpage','amount','plan','duration']:
            out[f'app_nonpay_{col}_share_{w}d']=safe(out[f'app_nonpay_{w}d_{col}'],out[f'app_all_{w}d_{col}'])
    out['app_t0_day_repaid_before_prediction']=int(day in paid_dates)
    return out

def family(name):
    if name.startswith('app_nonpay'):return '非还款日行为'
    if name.startswith(('app_all','app_t0','app_days','app_history')):return '全量App行为'
    if name.startswith(('repay','apply_settle','remit_settle','trigger')):return '提前还款与借还周期'
    if name.startswith('reborrow'):return '结清后续借习惯'
    if name.startswith('cash'):return '真实支付流水'
    if name.startswith(('util','demand','interaction')):return '需求使用率与交互'
    if name.startswith('offer'):return '历史获额与额度变化'
    if name.startswith('loan'):return '历史订单条件'
    if name.startswith('current_'):return '当前产品与变额条件'
    return '借款生命周期'
