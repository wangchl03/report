四、建议的 OKR 提升方向

整体策略分为“当天主转化、延迟用户承接、循环贷专项挖掘”三条线：第一条决定大盘，后两条负责承接与增量。

01把 T0 提单率作为主 OKR

主方向

以结清 0 在贷用户的 T0 当日提单率为核心结果指标。7 月基线为 40.78%，建议优先通过价格、额度、券、页面与触达时点实验提升即时决策；每提升 3 个百分点，按 7 月量级约增加 715 笔当日提单。

02继续 T5、T7+ 拦截策略

延迟承接

对 T0 未转化用户继续实施 T5、T7+ 分层拦截与召回，承接未在当天完成提单的用户。该方向不替代 T0 主目标，而是用于扩大后续转化增量，并按分层持续评估券策略与触达频次。

03测试循环贷订单的有效提单策略

增量探索

循环贷可提单订单有 189,470 笔，占全部可提单订单 44.13%，体量最大。应独立开展价格、券、额度与触达时点测试，筛选出对循环贷提单率真正有效的策略，形成第二条可规模化提升路径。

OKR 建议：主 OKR 聚焦“结清 0 在贷 T0 当日提单率提升”；T5、T7+ 作为 T0 未转化用户的后续承接策略；循环贷作为独立的增长实验方向。三条线分别用 T0 提单率、T5/T7+ 分层转化率、循环贷提单率评估，避免用单一总提单率掩盖策略效果。
