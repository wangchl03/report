二、测算口径

样本与事件

循环贷、成功放款、已结清且 overdue_days<0。统计单位为“用户×提前结清时刻”；同一用户同一时刻结清多笔订单合并为一次事件。

成本与现金

减免成本采用订单表 discount_amount 合计；真实到账采用还款流水表 amount，不把应还账面金额误当作实际现金。

后续订单归属

后续订单只归给申请前最近一次提前结清事件，并要求发生在下一次提前结清事件之前，避免同一订单被多个事件重复认领。

政策成本提前结清减免金额
→
用户回流D0 / D7 / D15 / D30提单与放款
→
后续收益D30内首笔放款订单D7实际现金利润
账面净回收 = 后续首笔订单D7实际现金利润 − 提前结清减免成本
增量净利润 = 实验组相对对照组的增量放款 × 单均利润 − 减免成本 − 增量资金成本 − 增量风险损失
结论边界：账面净回收把用户本来可能发生的回流利润也计入提前结清事件之后，因此不是政策的因果增量利润。资金释放收益和风险收益没有进入主结论。

七、因果盈亏平衡：账面覆盖不等于政策划算

观察性差值 vs 盈亏平衡要求

同样采用1—6月成熟有减免主样本；要求值按首笔D7放款单均利润计算。

计算过程

后续放款单均D7利润 = MXN 542.96
需要新增放款 = MXN 6,862,801.27 ÷ MXN 542.96 ≈ 12,640笔
所需增量放款率 = 12,640 ÷ 25,886 ≈ 48.83pp

有减免组当前D30放款率已为75.84%，剩余理论提升空间只有24.16pp；仅依靠把未放款事件转成一笔同等利润订单，无法覆盖全量减免成本。

这不否定账面已回收，而是说明现有回流利润中绝大部分不可能全部由减免政策新增促成。

政策决策应看增量：账面归因ROI为+55.33%，但标准化放款率差值为-0.25pp；要证明政策划算，必须通过随机保留组测得D30增量放款与增量净利润。

八、策略建议与验证方案

1｜先处理15天及以上段

  • 设置减免金额上限或降低减免比例。
  • 设置低减免组和无减免保留组。
  • 单独监控D30增量放款率与增量净利润。

2｜1—14天暂不盲目扩张

  • 账面回收为正，但未证明因果增量。
  • 可维持现状，并同步纳入分层随机实验。
  • 避免只根据账面ROI扩大优惠。

3｜实验设计

  • 按月份、提前天数、历史放款次数、上一笔金额分层随机。
  • 设置当前减免、低减免、5%—10%无减免保留组三档。
  • 对照组与实验组保持同一观察成熟标准。

4｜决策指标

  • 主指标：D30增量放款率、D30增量净利润。
  • 辅助：D0/D7提单与放款、后续订单D7/到期利润、逾期率。
  • 停止规则：若增量利润持续不能覆盖减免，收紧对应分层。

完整样本

1—9月共70,899次提前结清事件、70,960笔结清订单；显式减免合计MXN 11,645,106.11。

减免覆盖

43,863次事件发生正减免，占全部事件61.87%。

成熟性

1—6月用于主结论；7—8月可用于回流率趋势但经济结果部分成熟；9月不用于ROI结论。

指标定义
  • D0：提前结清自然日当天。
  • D7：结清当天至D+6，共7个自然日。
  • D15：结清当天至D+14，共15个自然日。
  • D30：结清当天至D+29，共30个自然日。
  • 后续首笔订单D7利润：到期日后7日内实际到账还款 − 放款本金。
  • 账面归因ROI：（后续首笔订单D7利润 − 减免成本）÷ 减免成本。
  • 经济成熟：D30回流窗口已结束，且后续首笔订单D7现金利润已经可观测；未放款事件也视为收益0且可观测。

执行说明：SQL固定观察截止日为2026-10-03，完整生成事件母表、月度指标、回流分层、提前天数、现金审计、标准化对照和因果盈亏平衡。资金释放收益代理仅为附加情景，不进入本报告主结论。
展开完整PGSQL（默认折叠）
-- =============================================================================
-- 循环贷提前结清是否划算：事件级账面经济性审计
--
-- 分析单位：用户 × 提前结清时刻。同一用户同一时刻结清多笔循环贷合并为一次事件。
-- 分析期：2026-01-01 至 2026-09-30；为复现本报告，数据观察截止固定为2026-10-03 00:00:00。
-- 后续订单归属：一笔后续订单只归属于其申请时间之前最近的一次提前结清事件。
-- 回流窗口：D0、D7、D15、D30 均按自然日左闭右开计算。
--
-- 官方可直接取数的成本：order_loan_f_v2_copy.discount_amount。
-- 抽样和全量审计显示，绝大多数提前结清订单满足：
--   订单累计应还(repaid_amt) - 还款流水到账合计 ≈ discount_amount，
-- 因此 discount_amount 可作为提前结清减免成本；差异额另外保留审计。
--
-- 资金释放收益没有直接字段，使用透明的情景估算：
--   剩余本金代理 = 原放款本金 × 提前天数 / 原贷款天数
--   资金收益代理 = 剩余本金代理 × 提前天数 × 15% / 365
-- 15%仅为情景参数，不代表公司的实际资金成本，可在 params 中替换。
--
-- “账面净收益”不是因果增量收益：
--   账面净收益 = 后续首笔放款订单利润 + 资金释放收益代理 - 减免成本。
-- 后续订单即使没有减免也可能自然发生；真正政策ROI仍需无减免对照/随机实验。
-- 风险收益没有直接、可靠字段，本SQL不把风险收益计入净收益。
-- =============================================================================

SET search_path TO wangchuanliang, public;
SET statement_timeout = 0;
SET query_dop = 1;

DROP TABLE IF EXISTS tmp_early_econ_params;
CREATE TEMP TABLE tmp_early_econ_params AS
SELECT DATE '2026-01-01' AS start_date,
       DATE '2026-10-01' AS end_date,
       DATE '2026-10-03' AS as_of_date,
       TIMESTAMP '2026-10-03 00:00:00' AS cutoff_ts,
       0.15::numeric AS annual_funding_cost_rate;

-- 只接受类型唯一且为2的循环贷订单，避免标签重复或冲突放大样本。
DROP TABLE IF EXISTS tmp_early_cycle_ids;
CREATE TEMP TABLE tmp_early_cycle_ids AS
SELECT serial_id
FROM wangchuanliang.side_recycle_type_copy
GROUP BY serial_id
HAVING COUNT(DISTINCT recycle_type) = 1
   AND MIN(recycle_type) = 2;

-- 一笔提前结清订单一行。
DROP TABLE IF EXISTS tmp_early_order;
CREATE TEMP TABLE tmp_early_order AS
SELECT o.user_id,
       o.serial_id,
       o.repaid_time,
       o.repaid_date::date AS repaid_date,
       o.due_date::date AS due_date,
       (-o.overdue_days)::integer AS early_days,
       COALESCE(o.remit_amt, 0)::numeric AS prior_remit_amt,
       COALESCE(o.discount_amount, 0)::numeric AS waiver_cost,
       COALESCE(o.repaid_amt, 0)::numeric AS booked_repaid_amt,
       COALESCE(o.loan_day, 0)::integer AS loan_day,
       COALESCE(o.total_term, 0)::integer AS total_term,
       COALESCE(o.remit_succ_rnb, 0)::integer AS prior_loan_count,
       o.product_no,
       -- 等额本金近似：剩余本金随剩余期限线性下降；该字段仅用于资金收益情景。
       CASE
           WHEN COALESCE(o.loan_day, 0) > 0 THEN
               COALESCE(o.remit_amt, 0)
               * LEAST(1.0, GREATEST(0.0, (-o.overdue_days)::numeric/o.loan_day))
           ELSE COALESCE(o.remit_amt, 0)
       END::numeric AS remaining_principal_proxy
FROM wangchuanliang.order_loan_f_v2_copy AS o
INNER JOIN tmp_early_cycle_ids AS c
        ON c.serial_id = o.serial_id
CROSS JOIN tmp_early_econ_params AS p
WHERE o.is_remit = 1
  AND o.loan_type = 'reloan'
  AND o.is_repaid = 1
  AND o.overdue_days < 0
  AND o.repaid_time > TIMESTAMP '2000-01-01 00:00:00'
  AND o.repaid_date >= p.start_date
  AND o.repaid_date <  p.end_date;

-- 流水到账审计：验证减免字段与“账面应还-实际到账”是否一致。
DROP TABLE IF EXISTS tmp_early_cash;
CREATE TEMP TABLE tmp_early_cash AS
SELECT e.serial_id,
       COALESCE(SUM(r.amount), 0)::numeric AS actual_cash_repaid
FROM tmp_early_order AS e
LEFT JOIN wangchuanliang.repayment_record_copy AS r
       ON r.serial_id = e.serial_id
GROUP BY e.serial_id;

-- 同一用户同一还款时刻的多笔提前结清合并成一次行为事件。
DROP TABLE IF EXISTS tmp_early_event;
CREATE TEMP TABLE tmp_early_event AS
SELECT x.*,
       ROW_NUMBER() OVER (
           PARTITION BY x.user_id
           ORDER BY x.event_time, x.event_serial_id
       ) AS event_no
FROM (
    SELECT e.user_id,
           e.repaid_time AS event_time,
           e.repaid_date AS event_date,
           MAX(e.serial_id) AS event_serial_id,
           COUNT(*)::bigint AS settled_order_n,
           SUM(e.prior_remit_amt)::numeric AS prior_remit_amt,
           SUM(e.waiver_cost)::numeric AS waiver_cost,
           SUM(e.remaining_principal_proxy)::numeric AS remaining_principal_proxy,
           SUM(e.remaining_principal_proxy * e.early_days
               * p.annual_funding_cost_rate / 365.0)::numeric
               AS capital_benefit_proxy,
           SUM(e.booked_repaid_amt - c.actual_cash_repaid)::numeric
               AS booked_cash_gap,
           MAX(e.early_days)::integer AS max_early_days,
           SUM(e.early_days*e.prior_remit_amt)
               / NULLIF(SUM(e.prior_remit_amt), 0) AS weighted_early_days,
           MAX(e.prior_loan_count)::integer AS prior_loan_count
    FROM tmp_early_order AS e
    INNER JOIN tmp_early_cash AS c
            ON c.serial_id = e.serial_id
    CROSS JOIN tmp_early_econ_params AS p
    GROUP BY e.user_id, e.repaid_time, e.repaid_date
) AS x;

-- 有关用户的后续申请订单，一笔订单只保留一行。
DROP TABLE IF EXISTS tmp_post_order;
CREATE TEMP TABLE tmp_post_order AS
SELECT user_id,
       serial_id,
       apply_time,
       apply_date::date AS apply_date,
       remit_time,
       remit_date::date AS remit_date,
       COALESCE(remit_amt, 0)::numeric AS remit_amt,
       due_date::date AS due_date,
       repaid_date::date AS repaid_date,
       is_remit,
       is_repaid,
       loan_status_code,
       remit_succ_rnb,
       product_no
FROM (
    SELECT o.*,
           ROW_NUMBER() OVER (
               PARTITION BY o.serial_id
               ORDER BY o.apply_time, o.remit_time DESC NULLS LAST
           ) AS rn
    FROM wangchuanliang.order_loan_f_v2_copy AS o
    INNER JOIN (SELECT DISTINCT user_id FROM tmp_early_event) AS u
            ON u.user_id = o.user_id
    CROSS JOIN tmp_early_econ_params AS p
    WHERE o.apply_time >= p.start_date::timestamp
      AND o.apply_time <  p.cutoff_ts
) AS x
WHERE rn = 1;

-- 时间线归属：订单申请落到它之前最近的一次提前结清事件。
DROP TABLE IF EXISTS tmp_post_assigned;
CREATE TEMP TABLE tmp_post_assigned AS
SELECT user_id,
       order_serial_id,
       apply_time,
       assigned_event_no
FROM (
    SELECT user_id,
           order_serial_id,
           apply_time,
           MAX(event_no) OVER (
               PARTITION BY user_id
               ORDER BY ts, sort_key, tie_id
               ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
           ) AS assigned_event_no
    FROM (
        SELECT e.user_id,
               e.event_time AS ts,
               0 AS sort_key,
               e.event_serial_id AS tie_id,
               e.event_no,
               NULL::bigint AS order_serial_id,
               NULL::timestamp AS apply_time
        FROM tmp_early_event AS e

        UNION ALL

        SELECT o.user_id,
               o.apply_time AS ts,
               1 AS sort_key,
               o.serial_id AS tie_id,
               NULL::bigint AS event_no,
               o.serial_id AS order_serial_id,
               o.apply_time
        FROM tmp_post_order AS o
    ) AS timeline
) AS assigned
WHERE order_serial_id IS NOT NULL
  AND assigned_event_no IS NOT NULL;

-- 每次提前结清事件之后的第一笔申请。
DROP TABLE IF EXISTS tmp_first_apply;
CREATE TEMP TABLE tmp_first_apply AS
SELECT user_id,
       assigned_event_no AS event_no,
       serial_id AS first_apply_serial_id,
       apply_time AS first_apply_time
FROM (
    SELECT a.user_id,
           a.assigned_event_no,
           o.serial_id,
           o.apply_time,
           ROW_NUMBER() OVER (
               PARTITION BY a.user_id, a.assigned_event_no
               ORDER BY o.apply_time, o.serial_id
           ) AS rn
    FROM tmp_post_assigned AS a
    INNER JOIN tmp_post_order AS o
            ON o.user_id = a.user_id
           AND o.serial_id = a.order_serial_id
) AS x
WHERE rn = 1;

-- 每次提前结清事件之后的第一笔成功放款（按申请时间归属、按放款时间取首笔）。
DROP TABLE IF EXISTS tmp_first_fund;
CREATE TEMP TABLE tmp_first_fund AS
SELECT user_id,
       assigned_event_no AS event_no,
       serial_id AS first_fund_serial_id,
       apply_time AS first_fund_apply_time,
       remit_time AS first_fund_time,
       remit_date AS first_fund_date,
       remit_amt AS first_fund_amt,
       due_date AS first_fund_due_date,
       repaid_date AS first_fund_repaid_date
FROM (
    SELECT a.user_id,
           a.assigned_event_no,
           o.serial_id,
           o.apply_time,
           o.remit_time,
           o.remit_date,
           o.remit_amt,
           o.due_date,
           o.repaid_date,
           ROW_NUMBER() OVER (
               PARTITION BY a.user_id, a.assigned_event_no
               ORDER BY o.remit_time, o.apply_time, o.serial_id
           ) AS rn
    FROM tmp_post_assigned AS a
    INNER JOIN tmp_post_order AS o
            ON o.user_id = a.user_id
           AND o.serial_id = a.order_serial_id
    WHERE o.is_remit = 1
      AND o.remit_time IS NOT NULL
) AS x
WHERE rn = 1;

-- 后续首笔成功放款的到期/D7现金利润。
DROP TABLE IF EXISTS tmp_first_fund_profit;
CREATE TEMP TABLE tmp_first_fund_profit AS
SELECT f.user_id,
       f.event_no,
       f.first_fund_serial_id,
       f.first_fund_amt,
       f.first_fund_due_date,
       COALESCE(SUM(CASE
           WHEN r.payin_date <= f.first_fund_due_date THEN r.amount ELSE 0
       END), 0)::numeric AS paid_by_due_amt,
       COALESCE(SUM(CASE
           WHEN r.payin_date <= f.first_fund_due_date + 7 THEN r.amount ELSE 0
       END), 0)::numeric AS paid_by_d7_amt
FROM tmp_first_fund AS f
LEFT JOIN wangchuanliang.repayment_record_copy AS r
       ON r.serial_id = f.first_fund_serial_id
GROUP BY f.user_id,
         f.event_no,
         f.first_fund_serial_id,
         f.first_fund_amt,
         f.first_fund_due_date;

-- 事件级最终底表。
DROP TABLE IF EXISTS tmp_early_event_econ;
CREATE TEMP TABLE tmp_early_event_econ AS
SELECT e.*,
       DATE_TRUNC('month', e.event_date)::date AS event_month,
       p.as_of_date,
       a.first_apply_serial_id,
       a.first_apply_time,
       f.first_fund_serial_id,
       f.first_fund_apply_time,
       f.first_fund_time,
       f.first_fund_amt,
       f.first_fund_due_date,
       fp.paid_by_due_amt,
       fp.paid_by_d7_amt,
       CASE WHEN a.first_apply_time >= e.event_time
                  AND a.first_apply_time < e.event_date + 1 THEN 1 ELSE 0 END AS is_d0_apply,
       CASE WHEN a.first_apply_time >= e.event_time
                  AND a.first_apply_time < e.event_date + 7 THEN 1 ELSE 0 END AS is_d7_apply,
       CASE WHEN a.first_apply_time >= e.event_time
                  AND a.first_apply_time < e.event_date + 15 THEN 1 ELSE 0 END AS is_d15_apply,
       CASE WHEN a.first_apply_time >= e.event_time
                  AND a.first_apply_time < e.event_date + 30 THEN 1 ELSE 0 END AS is_d30_apply,
       CASE WHEN f.first_fund_apply_time >= e.event_time
                  AND f.first_fund_apply_time < e.event_date + 7 THEN 1 ELSE 0 END AS is_d7_fund,
       CASE WHEN f.first_fund_apply_time >= e.event_time
                  AND f.first_fund_apply_time < e.event_date + 15 THEN 1 ELSE 0 END AS is_d15_fund,
       CASE WHEN f.first_fund_apply_time >= e.event_time
                  AND f.first_fund_apply_time < e.event_date + 30 THEN 1 ELSE 0 END AS is_d30_fund,
       CASE WHEN f.first_fund_apply_time >= e.event_time
                  AND f.first_fund_apply_time < e.event_date + 30
                  AND f.first_fund_due_date < p.as_of_date
            THEN fp.paid_by_due_amt - f.first_fund_amt END AS followup_due_profit,
       CASE WHEN f.first_fund_apply_time >= e.event_time
                  AND f.first_fund_apply_time < e.event_date + 30
                  AND f.first_fund_due_date + 7 < p.as_of_date
            THEN fp.paid_by_d7_amt - f.first_fund_amt END AS followup_d7_profit,
       CASE WHEN e.event_date + 30 <= p.as_of_date THEN 1 ELSE 0 END AS is_d30_event_mature,
       CASE
           WHEN e.event_date + 30 <= p.as_of_date
            AND (
                f.first_fund_serial_id IS NULL
                OR f.first_fund_apply_time >= e.event_date + 30
                OR f.first_fund_due_date < p.as_of_date
            )
           THEN 1 ELSE 0
       END AS is_due_econ_observable,
       CASE
           WHEN e.event_date + 30 <= p.as_of_date
            AND (
                f.first_fund_serial_id IS NULL
                OR f.first_fund_apply_time >= e.event_date + 30
                OR f.first_fund_due_date + 7 < p.as_of_date
            )
           THEN 1 ELSE 0
       END AS is_d7_econ_observable
FROM tmp_early_event AS e
CROSS JOIN tmp_early_econ_params AS p
LEFT JOIN tmp_first_apply AS a
       ON a.user_id = e.user_id
      AND a.event_no = e.event_no
LEFT JOIN tmp_first_fund AS f
       ON f.user_id = e.user_id
      AND f.event_no = e.event_no
LEFT JOIN tmp_first_fund_profit AS fp
       ON fp.user_id = e.user_id
      AND fp.event_no = e.event_no;

-- =============================================================================
-- 结果0A：主结论（严格成熟、实际有减免、2026年1—6月）。
-- 主结论只用可观测数据，不计15%资金收益代理：
--   账面净回收 = 后续首笔放款D7实际现金利润 - 显式减免成本。
-- 1—6月各月的D30与后续订单D7观察均已完全成熟，避免右删失。
-- =============================================================================
SELECT COUNT(*) AS policy_mature_event_n,
       COUNT(DISTINCT user_id) AS user_n,
       ROUND(SUM(waiver_cost), 2) AS waiver_cost,
       ROUND(100.0*SUM(is_d30_apply)/NULLIF(COUNT(*), 0), 2) AS d30_apply_rate_pct,
       ROUND(100.0*SUM(is_d30_fund)/NULLIF(COUNT(*), 0), 2) AS d30_fund_rate_pct,
       ROUND(SUM(COALESCE(followup_d7_profit, 0)), 2) AS followup_d7_profit,
       ROUND(SUM(COALESCE(followup_d7_profit, 0)-waiver_cost), 2)
           AS gross_net_after_waiver,
       ROUND(100.0*SUM(COALESCE(followup_d7_profit, 0))
             /NULLIF(SUM(waiver_cost), 0), 2) AS profit_to_waiver_pct,
       ROUND(100.0*SUM(COALESCE(followup_d7_profit, 0)-waiver_cost)
             /NULLIF(SUM(waiver_cost), 0), 2) AS gross_roi_pct
FROM tmp_early_event_econ
WHERE event_month < DATE '2026-07-01'
  AND waiver_cost > 0
  AND is_d7_econ_observable = 1;

-- =============================================================================
-- 结果0B：观察性盈亏平衡门槛（2026年1—8月）。
-- 不计资金收益代理；回答“减免至少要额外增加多少后续放款，才覆盖减免成本”。
-- 这是经营门槛，不是已经实现的增量结果。
-- =============================================================================
WITH break_even_base AS (
    SELECT COUNT(*) AS event_n,
           SUM(CASE WHEN is_d7_econ_observable=1 THEN 1 ELSE 0 END) AS observable_n,
           SUM(CASE WHEN is_d7_econ_observable=1 THEN is_d30_fund ELSE 0 END)
               AS observed_funded_n,
           SUM(waiver_cost) AS waiver_cost,
           SUM(CASE WHEN is_d7_econ_observable=1
                    THEN COALESCE(followup_d7_profit, 0) ELSE 0 END) AS followup_d7_profit
    FROM tmp_early_event_econ
    WHERE event_month < DATE '2026-09-01'
), break_even_calc AS (
    SELECT b.*,
           followup_d7_profit/NULLIF(observed_funded_n, 0) AS profit_per_funded_order
    FROM break_even_base AS b
)
SELECT event_n,
       observable_n,
       observed_funded_n,
       ROUND(waiver_cost, 2) AS waiver_cost,
       ROUND(followup_d7_profit, 2) AS followup_d7_profit,
       ROUND(profit_per_funded_order, 2) AS profit_per_funded_order,
       ROUND(waiver_cost/NULLIF(profit_per_funded_order, 0), 2)
           AS break_even_extra_funded_orders,
       ROUND(100.0*(waiver_cost/NULLIF(profit_per_funded_order, 0))
             /NULLIF(event_n, 0), 2) AS break_even_extra_fund_rate_pp
FROM break_even_calc;

-- =============================================================================
-- 结果0C：与主结论完全同口径的因果盈亏平衡门槛（1—6月成熟有减免样本）。
-- 解释：若把全部减免成本视为政策投入，政策需要真正额外促成多少D30放款，
-- 才能用这些新增订单的首笔D7利润覆盖投入。该门槛不是已实现的增量结果。
-- =============================================================================
WITH mature_policy AS (
    SELECT COUNT(*) AS event_n,
           SUM(is_d30_fund) AS observed_funded_n,
           SUM(waiver_cost) AS waiver_cost,
           SUM(COALESCE(followup_d7_profit, 0)) AS followup_d7_profit
    FROM tmp_early_event_econ
    WHERE event_month < DATE '2026-07-01'
      AND waiver_cost > 0
      AND is_d7_econ_observable = 1
), calc AS (
    SELECT m.*,
           followup_d7_profit/NULLIF(observed_funded_n, 0)
               AS d7_profit_per_funded_order
    FROM mature_policy AS m
)
SELECT event_n,
       observed_funded_n,
       ROUND(waiver_cost, 2) AS waiver_cost,
       ROUND(followup_d7_profit, 2) AS followup_d7_profit,
       ROUND(d7_profit_per_funded_order, 2) AS d7_profit_per_funded_order,
       ROUND(waiver_cost/NULLIF(d7_profit_per_funded_order, 0), 2)
           AS break_even_incremental_funded_order_n,
       ROUND(100.0*waiver_cost/NULLIF(d7_profit_per_funded_order, 0)
             /NULLIF(event_n, 0), 2) AS break_even_incremental_fund_rate_pp
FROM calc;

-- =============================================================================
-- 结果1：月度回流、减免成本与账面经济性。
-- 账面经济性只在“D30窗口已成熟且后续订单利润已成熟/无后续放款”的事件上计算。
-- =============================================================================
SELECT TO_CHAR(event_month, 'YYYY-MM') AS month,
       COUNT(*) AS early_event_n,
       SUM(settled_order_n) AS early_order_n,
       COUNT(DISTINCT user_id) AS user_n,
       ROUND(SUM(waiver_cost), 2) AS waiver_cost,
       ROUND(SUM(waiver_cost)/NULLIF(COUNT(*), 0), 2) AS waiver_per_event,
       ROUND(100.0*SUM(CASE WHEN waiver_cost > 0 THEN 1 ELSE 0 END)
             /NULLIF(COUNT(*), 0), 2) AS waiver_event_share_pct,
       ROUND(SUM(capital_benefit_proxy), 2) AS capital_benefit_proxy_15pct,
       ROUND(100.0*SUM(is_d0_apply)/NULLIF(COUNT(*), 0), 2) AS d0_apply_rate_pct,
       ROUND(100.0*SUM(is_d7_apply)/NULLIF(COUNT(*), 0), 2) AS d7_apply_rate_pct,
       ROUND(100.0*SUM(is_d15_apply)/NULLIF(COUNT(*), 0), 2) AS d15_apply_rate_pct,
       ROUND(100.0*SUM(CASE WHEN is_d30_event_mature=1 THEN is_d30_apply ELSE 0 END)
             /NULLIF(SUM(is_d30_event_mature), 0), 2) AS d30_apply_rate_pct,
       ROUND(100.0*SUM(CASE WHEN is_d30_event_mature=1 THEN is_d30_fund ELSE 0 END)
             /NULLIF(SUM(is_d30_event_mature), 0), 2) AS d30_fund_rate_pct,

       SUM(is_due_econ_observable) AS due_econ_event_n,
       ROUND(SUM(CASE WHEN is_due_econ_observable=1 THEN waiver_cost ELSE 0 END), 2)
           AS due_econ_waiver_cost,
       ROUND(SUM(CASE WHEN is_due_econ_observable=1 THEN capital_benefit_proxy ELSE 0 END), 2)
           AS due_econ_capital_benefit,
       ROUND(SUM(CASE WHEN is_due_econ_observable=1
                      THEN COALESCE(followup_due_profit, 0) ELSE 0 END), 2)
           AS followup_due_profit,
       ROUND(SUM(CASE WHEN is_due_econ_observable=1
                      THEN COALESCE(followup_due_profit, 0)
                           + capital_benefit_proxy - waiver_cost ELSE 0 END), 2)
           AS gross_due_net_benefit,
       ROUND(SUM(CASE WHEN is_due_econ_observable=1
                      THEN COALESCE(followup_due_profit, 0)
                           + capital_benefit_proxy - waiver_cost ELSE 0 END)
             /NULLIF(SUM(CASE WHEN is_due_econ_observable=1 THEN waiver_cost ELSE 0 END), 0), 4)
           AS gross_due_net_roi,

       SUM(is_d7_econ_observable) AS d7_econ_event_n,
       ROUND(SUM(CASE WHEN is_d7_econ_observable=1 THEN waiver_cost ELSE 0 END), 2)
           AS d7_econ_waiver_cost,
       ROUND(SUM(CASE WHEN is_d7_econ_observable=1 THEN capital_benefit_proxy ELSE 0 END), 2)
           AS d7_econ_capital_benefit,
       ROUND(SUM(CASE WHEN is_d7_econ_observable=1
                      THEN COALESCE(followup_d7_profit, 0) ELSE 0 END), 2)
           AS followup_d7_profit,
       ROUND(SUM(CASE WHEN is_d7_econ_observable=1
                      THEN COALESCE(followup_d7_profit, 0)
                           + capital_benefit_proxy - waiver_cost ELSE 0 END), 2)
           AS gross_d7_net_benefit,
       ROUND(SUM(CASE WHEN is_d7_econ_observable=1
                      THEN COALESCE(followup_d7_profit, 0)
                           + capital_benefit_proxy - waiver_cost ELSE 0 END)
             /NULLIF(SUM(CASE WHEN is_d7_econ_observable=1 THEN waiver_cost ELSE 0 END), 0), 4)
           AS gross_d7_net_roi
FROM tmp_early_event_econ
GROUP BY event_month
ORDER BY event_month;

-- 结果1B：1—8月成熟样本的盈亏平衡要求。
-- 必要增量放款率 =（减免成本－资金释放收益代理）/ 后续首笔D7平均利润 / 事件数。
-- 该指标回答：政策至少要额外带来多少放款，才能覆盖政策成本。
SELECT COUNT(*) AS early_event_n,
       SUM(is_d7_econ_observable) AS d7_econ_event_n,
       SUM(CASE WHEN is_d7_econ_observable=1 AND is_d30_fund=1
                THEN 1 ELSE 0 END) AS d30_funded_event_n,
       ROUND(SUM(CASE WHEN is_d7_econ_observable=1
                      THEN waiver_cost ELSE 0 END), 2) AS waiver_cost,
       ROUND(SUM(CASE WHEN is_d7_econ_observable=1
                      THEN capital_benefit_proxy ELSE 0 END), 2)
           AS capital_benefit_proxy_15pct,
       ROUND(SUM(CASE WHEN is_d7_econ_observable=1
                      THEN COALESCE(followup_d7_profit,0) ELSE 0 END), 2)
           AS followup_d7_profit,
       ROUND(AVG(CASE WHEN is_d7_econ_observable=1 AND is_d30_fund=1
                      THEN followup_d7_profit END), 2)
           AS d7_profit_per_funded_order,
       ROUND(
           (SUM(CASE WHEN is_d7_econ_observable=1
                     THEN waiver_cost-capital_benefit_proxy ELSE 0 END)
            /NULLIF(AVG(CASE WHEN is_d7_econ_observable=1 AND is_d30_fund=1
                             THEN followup_d7_profit END), 0)),
           2
       ) AS break_even_incremental_funded_order_n,
       ROUND(
           100.0
           *(SUM(CASE WHEN is_d7_econ_observable=1
                      THEN waiver_cost-capital_benefit_proxy ELSE 0 END)
             /NULLIF(AVG(CASE WHEN is_d7_econ_observable=1 AND is_d30_fund=1
                              THEN followup_d7_profit END), 0))
           /NULLIF(SUM(is_d7_econ_observable), 0),
           4
       ) AS break_even_incremental_fund_rate_pp
FROM tmp_early_event_econ
WHERE event_month < DATE '2026-09-01';

-- =============================================================================
-- 结果2：按回流速度分层。用于判断“快速回流是否覆盖减免，长期不回流是否亏损”。
-- =============================================================================
SELECT CASE
           WHEN first_fund_apply_time >= event_time
            AND first_fund_apply_time < event_date + 7 THEN 'D0-D6放款'
           WHEN first_fund_apply_time >= event_date + 7
            AND first_fund_apply_time < event_date + 15 THEN 'D7-D14放款'
           WHEN first_fund_apply_time >= event_date + 15
            AND first_fund_apply_time < event_date + 30 THEN 'D15-D29放款'
           WHEN is_d30_event_mature=1 THEN 'D30内未放款'
           ELSE 'D30观察未成熟'
       END AS return_bucket,
       COUNT(*) AS event_n,
       ROUND(100.0*COUNT(*)/SUM(COUNT(*)) OVER (), 2) AS event_share_pct,
       ROUND(SUM(waiver_cost), 2) AS waiver_cost,
       ROUND(SUM(waiver_cost)/NULLIF(COUNT(*), 0), 2) AS waiver_per_event,
       ROUND(SUM(capital_benefit_proxy), 2) AS capital_benefit_proxy_15pct,
       SUM(is_d7_econ_observable) AS d7_econ_event_n,
       ROUND(SUM(CASE WHEN is_d7_econ_observable=1
                      THEN COALESCE(followup_d7_profit, 0) ELSE 0 END), 2)
           AS followup_d7_profit,
       ROUND(SUM(CASE WHEN is_d7_econ_observable=1
                      THEN COALESCE(followup_d7_profit, 0)
                           + capital_benefit_proxy - waiver_cost ELSE 0 END), 2)
           AS gross_d7_net_benefit
FROM tmp_early_event_econ
GROUP BY CASE
             WHEN first_fund_apply_time >= event_time
              AND first_fund_apply_time < event_date + 7 THEN 'D0-D6放款'
             WHEN first_fund_apply_time >= event_date + 7
              AND first_fund_apply_time < event_date + 15 THEN 'D7-D14放款'
             WHEN first_fund_apply_time >= event_date + 15
              AND first_fund_apply_time < event_date + 30 THEN 'D15-D29放款'
             WHEN is_d30_event_mature=1 THEN 'D30内未放款'
             ELSE 'D30观察未成熟'
         END
ORDER BY return_bucket;

-- =============================================================================
-- 结果3：按提前天数分层。提前越多，通常减免越大；用于找亏损拐点。
-- 只使用1—8月成熟度较高的样本。
-- =============================================================================
SELECT CASE
           WHEN max_early_days=1 THEN '1天'
           WHEN max_early_days<=3 THEN '2-3天'
           WHEN max_early_days<=7 THEN '4-7天'
           WHEN max_early_days<=14 THEN '8-14天'
           ELSE '15天以上'
       END AS early_day_bucket,
       COUNT(*) AS event_n,
       ROUND(AVG(waiver_cost), 2) AS waiver_per_event,
       ROUND(100.0*SUM(CASE WHEN is_d30_event_mature=1 THEN is_d30_fund ELSE 0 END)
             /NULLIF(SUM(is_d30_event_mature), 0), 2) AS d30_fund_rate_pct,
       SUM(is_d7_econ_observable) AS d7_econ_event_n,
       ROUND(
           SUM(CASE WHEN is_d7_econ_observable=1
                    THEN COALESCE(followup_d7_profit,0)
                         + capital_benefit_proxy-waiver_cost ELSE 0 END)
           /NULLIF(SUM(is_d7_econ_observable), 0),
           2
       ) AS gross_d7_net_benefit_per_event
FROM tmp_early_event_econ
WHERE event_month < DATE '2026-09-01'
GROUP BY CASE
             WHEN max_early_days=1 THEN '1天'
             WHEN max_early_days<=3 THEN '2-3天'
             WHEN max_early_days<=7 THEN '4-7天'
             WHEN max_early_days<=14 THEN '8-14天'
             ELSE '15天以上'
         END
ORDER BY MIN(max_early_days);

-- =============================================================================
-- 结果4：减免成本字段审计。
-- =============================================================================
SELECT COUNT(*) AS early_order_n,
       SUM(CASE WHEN ABS(waiver_cost-(booked_repaid_amt-actual_cash_repaid)) < 0.01
                THEN 1 ELSE 0 END) AS exact_match_n,
       ROUND(100.0*SUM(CASE WHEN ABS(waiver_cost-(booked_repaid_amt-actual_cash_repaid)) < 0.01
                            THEN 1 ELSE 0 END)/NULLIF(COUNT(*), 0), 2) AS exact_match_pct,
       ROUND(SUM(waiver_cost), 2) AS official_waiver_cost,
       ROUND(SUM(booked_repaid_amt-actual_cash_repaid), 2) AS booked_cash_gap,
       ROUND(SUM(booked_repaid_amt-actual_cash_repaid)-SUM(waiver_cost), 2)
           AS difference_amt
FROM tmp_early_order AS e
INNER JOIN tmp_early_cash AS c
        ON c.serial_id = e.serial_id;

-- =============================================================================
-- 结果5：观察性对照（不是因果实验）。
-- 仅用1—8月成熟事件；按月份、提前天数、历史放款次数、上一笔放款金额千元档、
-- 同刻结清订单数精确分层。用有减免组结构加权无减免组D30放款率。
-- “有减免－标准化无减免”仅作证据强弱判断，不可替代随机实验。
-- =============================================================================
WITH matched_base AS (
    SELECT event_month,
           max_early_days,
           CASE WHEN prior_loan_count >= 6 THEN 6 ELSE prior_loan_count END
               AS loan_count_bucket,
           FLOOR(prior_remit_amt/1000) AS amount_band,
           settled_order_n,
           CASE WHEN waiver_cost > 0 THEN 1 ELSE 0 END AS is_waiver,
           is_d30_fund
    FROM tmp_early_event_econ
    WHERE event_month < DATE '2026-09-01'
      AND is_d30_event_mature = 1
), stratum AS (
    SELECT event_month,
           max_early_days,
           loan_count_bucket,
           amount_band,
           settled_order_n,
           SUM(CASE WHEN is_waiver=1 THEN 1 ELSE 0 END) AS waiver_n,
           SUM(CASE WHEN is_waiver=1 THEN is_d30_fund ELSE 0 END) AS waiver_fund_n,
           SUM(CASE WHEN is_waiver=0 THEN 1 ELSE 0 END) AS no_waiver_n,
           SUM(CASE WHEN is_waiver=0 THEN is_d30_fund ELSE 0 END) AS no_waiver_fund_n
    FROM matched_base
    GROUP BY event_month,
             max_early_days,
             loan_count_bucket,
             amount_band,
             settled_order_n
), common_support AS (
    SELECT *
    FROM stratum
    WHERE waiver_n > 0
      AND no_waiver_n > 0
)
SELECT SUM(waiver_n) AS matched_waiver_event_n,
       (SELECT SUM(CASE WHEN is_waiver=1 THEN 1 ELSE 0 END)
        FROM matched_base) AS all_waiver_event_n,
       ROUND(100.0*SUM(waiver_n)
             /NULLIF((SELECT SUM(CASE WHEN is_waiver=1 THEN 1 ELSE 0 END)
                      FROM matched_base), 0), 4) AS coverage_pct,
       ROUND(100.0*SUM(waiver_fund_n)/NULLIF(SUM(waiver_n), 0), 4)
           AS waiver_group_d30_fund_rate_pct,
       ROUND(100.0*SUM(waiver_n*(no_waiver_fund_n::numeric/no_waiver_n))
             /NULLIF(SUM(waiver_n), 0), 4)
           AS standardized_no_waiver_d30_fund_rate_pct,
       ROUND(
           100.0*SUM(waiver_fund_n)/NULLIF(SUM(waiver_n), 0)
           - 100.0*SUM(waiver_n*(no_waiver_fund_n::numeric/no_waiver_n))
             /NULLIF(SUM(waiver_n), 0),
           4
       ) AS descriptive_delta_pp,
       COUNT(*) AS support_strata_n
FROM common_support;
