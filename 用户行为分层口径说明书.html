用户行为分层口径说明书

基于 event_track_record 事件级埋点 · 对照组分群 · 2026年8月

一、分层定义

分层SQL 条件含义
沉默型app_starts_p1 = 0一期 4 天内，APP 从未被启动
犹豫型app_starts_p1 > 0 AND newpage_p1 < 6有 APP 活跃，但进入借款页不足 6 次
自主型newpage_p1 >= 6进入借款页 6 次以上，有明确借款研究行为

二、指标口径

变量计算方式数据源
app_starts_p1COUNT(event_type = 'app_start') —— 一期 APP 启动总次数event_track_record
newpage_p1COUNT(event_type = 'page_view_in' AND props_id IN ('Loan_newpage', 'Loan_newpage_select')) —— 一期进入借款页总次数event_track_record
一期时间窗口各批次发券前 4 天（0716_0721 批次 → 2026-07-17 至 2026-07-20，依此类推）—
提单标签二期 7 天内 order_loan_f_v2_copy 中有提单记录order_loan_f_v2_copy
二期时间窗口各批次发券后 7 天（0716_0721 批次 → 2026-07-21 至 2026-07-27）—

* 进入借款页仅统计 page_view_in，不重复计入 page_view_out

三、样本范围

维度口径
用户来源四组 AB 测试表（wangchuanliang.no_apply_0716_0721_30pct 至 0719_0724_30pct）
分组仅对照组（ab_group = 'control'），共 657 人
前提用户全部订单已结清，no_apply 期间（发券前）无提单

四、分层 SQL

WITH users AS (
    SELECT churn_user_id AS user_id 
    FROM wangchuanliang.no_apply_0716_0721_30pct WHERE ab_group = 'control'
    UNION ALL SELECT churn_user_id FROM wangchuanliang.no_apply_0717_0722_30pct WHERE ab_group = 'control'
    UNION ALL SELECT churn_user_id FROM wangchuanliang.no_apply_0718_0723_30pct WHERE ab_group = 'control'
    UNION ALL SELECT churn_user_id FROM wangchuanliang.no_apply_0719_0724_30pct WHERE ab_group = 'control'
),
p1_events AS (
    SELECT user_id,
           COUNT(CASE WHEN event_type = 'app_start' THEN 1 END) AS app_starts,
           COUNT(CASE WHEN event_type = 'page_view_in' 
                 AND props_id IN ('Loan_newpage', 'Loan_newpage_select') THEN 1 END) AS newpage
    FROM wangchuanliang.event_track_record
    WHERE create_date IN ('2026-07-17','2026-07-18','2026-07-19','2026-07-20',
                          '2026-07-21','2026-07-22','2026-07-23')
    GROUP BY user_id
)
SELECT u.user_id,
       CASE
           WHEN COALESCE(e.app_starts, 0) = 0 THEN '沉默型'
           WHEN COALESCE(e.newpage, 0) >= 6 THEN '自主型'
           ELSE '犹豫型'
       END AS segment
FROM users u
LEFT JOIN p1_events e ON u.user_id = e.user_id
