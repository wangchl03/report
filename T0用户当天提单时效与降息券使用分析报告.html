二、统计口径

严格 T0 基础样本用户结清时没有其他在途订单；结清当日获额通过，且获额时间不早于结清时间；同一用户同日保留最早合格结清记录。
当天首次提单在该合格结清记录后，于结清当日发生的最早一笔提单订单。统计粒度为“用户 × 合格结清日期”。
降息券使用提单订单以 user_id + serial_id 关联红包表；存在 type=3 记录即标记为使用降息券，不纳入 type=2 还款优惠券。

三、当日提单率：大盘持续下滑

当日提单率 = 当天首次提单订单数 / 当月严格 T0 基础样本数。

结论 1：1 月至 7 月，当日提单率由 52.91% 降至 41.36%，下降 11.55 个百分点。说明即时提单能力或即时提单意愿正在走弱；8 月为未完整月度，适合持续观察。

四、降息券使用率与提单率：同向比较

左轴为当日提单率，右轴为当天首次提单订单的总体降息券使用率。两项指标分母不同，仅用于观察月度共同变化，不用于直接判断因果。

结论 2：两项指标不存在稳定的同步变化

当日提单率从 1 月的 52.91% 持续下滑至 7 月的 41.36%，但总体降息券使用率在 1 月至 5 月由 5.07% 降至 1.40%，随后 6—7 月又升至 3.87% 和 7.43%。因此，仅从月度趋势不能证明“发券更多或更少”直接造成当日提单率变化。

建议：以延迟未提单用户为实验对象验证

应固定在获额后 3 小时仍未提单的用户内，对比发券与未发券的后续当天提单率；再同步比较放款、逾期、盈利和券成本，才能识别优惠券的真实增量效果。

结论 4：各月后段提单订单的降息券使用率均更高

例如 7 月，获额后 3 小时内提单订单的用券率为 7.02%，3 小时后为 11.15%，高出 4.13 个百分点。该差异与“3 小时未提单后发券”的策略方向一致。

解读边界：不能仅凭用券率判断券的增量效果

3 小时后用户本身就是未即时转化的人群，通常提单意愿更弱、价格敏感度更高。要评估优惠券带来的增量，应在同类延迟用户内设置未发券对照组，同时观察提单率、放款率、逾期率和红包成本后的盈利率。

八、建议的下一步验证

建立 3 小时后人群的随机对照

在“获额通过后 3 小时仍未提单”的严格 T0 用户中，随机分为发降息券与不发券两组；分别计算 3 小时后至当日结束的增量提单率。

同时观察质量指标

除增量提单外，应同步对比放款成功率、逾期率、盈利率和红包金额。只有增量转化覆盖红包成本且风险质量稳定，才适合扩大策略。

附录：完整 PGSQL

以下代码覆盖严格 T0 样本、当天首次提单时效、降息券使用及月度汇总结果；当前版本对应 2026-01-01 至 2026-08-25。

▸总体首次提单时效统计
/* ================================================================
   T0 用户当天首次提单时效与降息券使用率（月度）
   统计范围：2026-01-01 至 2026-08-25

   1. 严格 T0：结清时点没有其他在途订单；
   2. 结清当日获额通过，且获额时间 >= 结清时间；
   3. 同一用户同日保留最早的合格结清记录；
   4. 当天首次提单须发生在对应获额通过之后；
   5. 降息券仅统计 coupon_user_detail_copy.type = 3。
   ================================================================ */
WITH params AS (
    SELECT DATE '2026-01-01' AS start_date,
           DATE '2026-08-25' AS end_date
),

/* 模块一：候选结清订单与严格“结清 0 在贷”判断 */
settled_orders AS (
    SELECT o.user_id, o.serial_id, o.repaid_time,
           o.repaid_date::date AS repaid_date
    FROM wangchuanliang.order_loan_f_v2_copy AS o
    CROSS JOIN params AS p
    WHERE o.is_remit = 1
      AND (o.is_repaid = 1
           OR o.loan_status_code = 7
           OR o.repaid_date::date > DATE '2000-01-01')
      AND o.repaid_time > TIMESTAMP '2000-01-01 00:00:00'
      AND o.repaid_date::date BETWEEN p.start_date AND p.end_date
),
candidate_users AS (
    SELECT DISTINCT user_id FROM settled_orders
),
all_orders AS (
    SELECT o.user_id, o.serial_id, o.apply_time,
           o.repaid_time, o.loan_status_code
    FROM wangchuanliang.order_loan_f_v2_copy AS o
    INNER JOIN candidate_users AS u ON u.user_id = o.user_id
),
clean_settles AS (
    SELECT s.*
    FROM settled_orders AS s
    WHERE NOT EXISTS (
        SELECT 1
        FROM all_orders AS o2
        WHERE o2.user_id = s.user_id
          AND o2.serial_id <> s.serial_id
          AND o2.apply_time < s.repaid_time
          AND (
                o2.loan_status_code IN (5, 8)
             OR (o2.loan_status_code = 7 AND o2.repaid_time > s.repaid_time)
          )
    )
),

/* 模块二：结清当日获额通过；同一秒获额、结清也纳入 */
passed_vir AS (
    SELECT v.user_id, v.vir_date::date AS vir_date,
           TO_TIMESTAMP(v.vir_unix) AS vir_time
    FROM wangchuanliang.order_vir_f_copy AS v
    CROSS JOIN params AS p
    WHERE v.is_pass1 = 1
      AND v.vir_date::date BETWEEN p.start_date AND p.end_date
),
settle_vir AS (
    SELECT c.user_id, c.serial_id AS settled_serial_id,
           c.repaid_date, c.repaid_time,
           MIN(v.vir_time) AS first_vir_time
    FROM clean_settles AS c
    INNER JOIN passed_vir AS v
      ON v.user_id = c.user_id
     AND v.vir_date = c.repaid_date
     AND v.vir_time >= c.repaid_time
    GROUP BY c.user_id, c.serial_id, c.repaid_date, c.repaid_time
),
base_sample AS (
    SELECT DISTINCT ON (user_id, repaid_date)
           user_id, settled_serial_id, repaid_date, repaid_time, first_vir_time
    FROM settle_vir
    ORDER BY user_id, repaid_date, repaid_time, settled_serial_id
),

/* 模块三：结清后、获额通过后，当天首次提单订单 */
d0_first_apply AS (
    SELECT b.user_id, b.repaid_date, b.first_vir_time,
           a.serial_id AS apply_serial_id, a.apply_time,
           ROW_NUMBER() OVER (
               PARTITION BY b.user_id, b.repaid_date
               ORDER BY a.apply_time, a.serial_id
           ) AS rn
    FROM base_sample AS b
    INNER JOIN all_orders AS a
      ON a.user_id = b.user_id
     AND a.serial_id <> b.settled_serial_id
     AND a.apply_time >= b.first_vir_time
     AND a.apply_time::date = b.repaid_date
),
d0_orders AS (
    SELECT user_id, repaid_date, first_vir_time, apply_serial_id, apply_time
    FROM d0_first_apply
    WHERE rn = 1
),

/* 模块四：订单级降息券。type=3 多期记录按订单去重。 */
interest_coupon_orders AS (
    SELECT DISTINCT user_id, serial_id
    FROM wangchuanliang.coupon_user_detail_copy
    WHERE type = 3
),
monthly AS (
    SELECT DATE_TRUNC('month', b.repaid_date)::date AS settle_month,
           COUNT(*) AS strict_t0_base_users,
           COUNT(d.apply_serial_id) AS d0_first_apply_users,
           COUNT(d.apply_serial_id)::numeric / NULLIF(COUNT(*), 0) AS d0_apply_rate,
           COUNT(*) FILTER (
               WHERE d.apply_time <= d.first_vir_time + INTERVAL '3 hours'
           ) AS apply_within_3h,
           COUNT(*) FILTER (
               WHERE d.apply_time > d.first_vir_time + INTERVAL '3 hours'
           ) AS apply_after_3h,
           COUNT(*) FILTER (WHERE c.serial_id IS NOT NULL) AS coupon_d0_orders,
           COUNT(*) FILTER (
               WHERE c.serial_id IS NOT NULL
                 AND d.apply_time <= d.first_vir_time + INTERVAL '3 hours'
           ) AS coupon_within_3h,
           COUNT(*) FILTER (
               WHERE c.serial_id IS NOT NULL
                 AND d.apply_time > d.first_vir_time + INTERVAL '3 hours'
           ) AS coupon_after_3h
    FROM base_sample AS b
    LEFT JOIN d0_orders AS d
      ON d.user_id = b.user_id AND d.repaid_date = b.repaid_date
    LEFT JOIN interest_coupon_orders AS c
      ON c.user_id = d.user_id AND c.serial_id = d.apply_serial_id
    GROUP BY 1
)
SELECT settle_month,
       strict_t0_base_users,
       d0_first_apply_users,
       ROUND(100 * d0_apply_rate, 2) AS d0_apply_rate_pct,
       apply_within_3h,
       apply_after_3h,
       ROUND(100 * apply_within_3h::numeric /
             NULLIF(d0_first_apply_users, 0), 2) AS within_3h_share_pct,
       ROUND(100 * apply_after_3h::numeric /
             NULLIF(d0_first_apply_users, 0), 2) AS after_3h_share_pct,
       coupon_d0_orders,
       ROUND(100 * coupon_d0_orders::numeric /
             NULLIF(d0_first_apply_users, 0), 2) AS coupon_use_rate_pct,
       coupon_within_3h,
       ROUND(100 * coupon_within_3h::numeric /
             NULLIF(apply_within_3h, 0), 2) AS coupon_within_3h_rate_pct,
       coupon_after_3h,
       ROUND(100 * coupon_after_3h::numeric /
             NULLIF(apply_after_3h, 0), 2) AS coupon_after_3h_rate_pct
FROM monthly
ORDER BY settle_month;
