一、为什么采用三项归因拆分

三类事件占比之和固定为100%，某一类占比增加必然对应其他类别减少。因此不能把“占比变化 × 该类绝对提单率”单独解释成该类的正负结构贡献。本报告把客群自身变化、客群替换以及占比对下降的放大或缓冲分开。

二、符号和完整恒等式

w₀：1月客群占比；w₁：8月客群占比；r₀：1月客群提单率；r₁：8月客群提单率；R₀：1月整体提单率（51.75%）。

整体提单率变化 = Σ〔w₀×(r₁−r₀) + (w₁−w₀)×(r₀−R₀) + (w₁−w₀)×(r₁−r₀)〕

三、五个指标的定义

基准档内效应

w₀ × (r₁ − r₀)

假设客群仍保持1月占比，仅计算该客群提单率变化对整体的影响。

纯结构效应

(w₁ − w₀) × (r₀ − R₀)

在1月提单率水平下，客群占比相对整体水平发生替换带来的影响。低于整体的客群占比增加为负。

交互效应

(w₁ − w₀) × (r₁ − r₀)

占比和提单率同时变化产生的额外影响：下降客群占比增加会放大下降，占比减少会形成缓冲。

结果档内效应（结果效应）

w₁ × (r₁ − r₀) = 基准档内效应 + 交互效应

按照8月实际客群占比计算的档内下降影响。若8月该类占比为0，结果档内效应即为0。

总归因贡献

结果档内效应 + 纯结构效应

某类客群对整体1—8月变化的最终归因值；三类合计等于整体提单率变化。

方向解释

  • 交互效应为负：占比变化放大该类下降。
  • 交互效应为正：占比变化缓冲该类下降。
  • 纯结构效应必须相对整体基准率解释。

六、逐类计算过程

额度降低

基准档内效应 = 32.01% ×（41.12% − 50.46%）= -2.99pp
纯结构效应 =（35.19% − 32.01%）×（50.46% − 51.75%）= -0.04pp
交互效应 =（35.19% − 32.01%）×（41.12% − 50.46%）= -0.30pp
结果档内效应 = 基准档内效应 + 交互效应 = -3.29pp
总归因贡献 = 结果档内效应 + 纯结构效应 = -3.33pp

额度不变

基准档内效应 = 8.61% ×（49.14% − 53.47%）= -0.37pp
纯结构效应 =（8.20% − 8.61%）×（53.47% − 51.75%）= -0.01pp
交互效应 =（8.20% − 8.61%）×（49.14% − 53.47%）= +0.02pp
结果档内效应 = 基准档内效应 + 交互效应 = -0.36pp
总归因贡献 = 结果档内效应 + 纯结构效应 = -0.36pp

额度增加

基准档内效应 = 59.38% ×（35.90% − 52.20%）= -9.68pp
纯结构效应 =（56.62% − 59.38%）×（52.20% − 51.75%）= -0.01pp
交互效应 =（56.62% − 59.38%）×（35.90% − 52.20%）= +0.45pp
结果档内效应 = 基准档内效应 + 交互效应 = -9.23pp
总归因贡献 = 结果档内效应 + 纯结构效应 = -9.24pp

七、结果校验

三类总归因贡献合计 = -12.93pp
8月整体提单率 − 1月整体提单率 = 38.82% − 51.75% = -12.93pp

两者尾差仅来自展示值四舍五入。PGSQL使用未四舍五入的原始比例计算。

八、解释边界

归因拆解是指标会计恒等式，用于判断下降来自哪里；它不证明额度策略具有因果效果。用户资质、基础额度、借款次数、历史使用率、流量渠道和页面行为仍可能共同影响提单率。
