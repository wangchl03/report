INSTALLMENT COUPON METHODOLOGY

分期订单红包使用统计口径说明

用于统一分期订单场景下还款优惠券、降息券和提额券的样本范围、数量、金额与防重规则。

金额粒度：分期订单（serial_id + current_term）数量粒度：整笔订单（serial_id + coupon_no）版本：2026-09-08
一、适用范围

统计对象与时间范围

本口径针对已放款的分期订单。每一条分期记录由 serial_id + current_term 唯一识别；整笔订单由 serial_id 唯一识别。示例 SQL 的窗口为 2025-07-01 至 2026-06-30，可替换为任意目标观察期。

分期订单样本

来源：wangchuanliang.repayment_plan_v2_copy；要求 is_remit = 1。

提单与到期窗口

整笔订单 apply_date 在窗口内，且该分期的 due_date_period 也在窗口内。

首贷 / 续贷分层

首贷：loan_type = 'firstloan'；续贷：loan_type = 'reloan'；总样本不限制贷款类型。

重要：样本条件同时限制“整笔订单提单日期”和“该分期到期日期”。窗口内提单、但该分期尚未在窗口内到期的记录，不会进入本分期订单统计样本。
二、统计流程

先确定分期样本，再按不同粒度计算指标

1. 筛选分期样本

保留已放款、提单日在窗口内、到期日在窗口内的分期记录。

2. 复合键关联红包

通过 serial_id + current_term 关联红包明细，金额归属到对应分期。

3. 分别计算数量与金额

数量回到整笔订单去重；金额、放款、折扣、还款保留分期粒度。

4. 汇总输出

可输出总计、提单月份、首贷/续贷等分层结果；比例均按汇总分子 / 汇总分母计算。

三、红包关联与分类

红包以分期复合键归属，数量以整笔订单去重

红包类别条件数量统计口径金额统计口径业务说明
还款优惠券type = 2在符合样本的红包记录中，COUNT(DISTINCT serial_id + ':' + coupon_no)按 serial_id + current_term 关联后，SUM(coupon_amount)同一整笔订单的不同期可存在不同 coupon_no；不同券号应分别计 1 张。
降息券type = 3按整笔订单 serial_id + coupon_no 去重按分期订单 serial_id + current_term 汇总通常一笔订单仅一个券号，但其降息金额可由系统等额或按规则分配到各期。
提额券type = 4按整笔订单 serial_id + coupon_no 去重按分期订单 serial_id + current_term 汇总一笔订单可同时使用提额券与降息券；两类券分别统计，不互相排斥。
数量与金额不能使用同一粒度：若一张降息券被拆分至多期，直接在分期粒度计数会重复计算券张数；但金额必须按分期相加，才能正确反映进入统计窗口的分期成本。
四、与红包统计的边界

本口径不统计折扣、还款与盈利

不包含分期折扣

discount_amount_period 属于订单折扣字段，不属于 coupon_user_detail_copy 中的红包明细，本说明和附录 SQL 均不汇总该字段。

不包含还款金额

repaid_amt_period 和还款流水 amount 不参与红包数量、红包金额的统计，也不在本附录 SQL 中输出。

不包含盈利指标

不计算盈利率、折扣后盈利率、降息券调整后盈利率或任何与放款、还款相关的比例。

五、防止重复统计

关键控制点

  1. 先筛分期样本：所有红包数量与金额只能基于符合窗口条件的 eligible_terms，不能从全量红包表直接统计。
  2. 红包金额使用复合键：关联条件必须同时包含 serial_id 和 current_term，使券金额只归属到实际对应的分期。
  3. 红包数量使用整笔订单维度：同一订单同一券号在多期出现时只计一次；不同券号则分别计数。
  4. 总计重新聚合：总计中的去重券数应对全样本重新 DISTINCT，不应简单相加月度去重值。
  5. 不同红包类型独立计量：同一订单同时使用降息券和提额券时，分别计入 type=3 与 type=4，不做互斥排除。
附录 A

完整可执行 PGSQL

以下代码仅输出总样本、首贷、续贷的总计和按提单月份分组的三类红包数量与金额，以及对应的样本分期订单数和整笔订单数。修改第一段窗口日期即可复用。

展开完整 PGSQL
WITH eligible_terms_raw AS (
    SELECT
        p.serial_id,
        p.current_term,
        p.user_id,
        p.loan_type,
        TO_CHAR(p.apply_date, 'YYYY-MM') AS apply_month
    FROM wangchuanliang.repayment_plan_v2_copy p
    WHERE p.is_remit = 1
      AND p.apply_date >= DATE '2025-07-01'
      AND p.apply_date <= DATE '2026-06-30'
      AND p.due_date_period >= DATE '2025-07-01'
      AND p.due_date_period <= DATE '2026-06-30'
),
eligible_terms AS (
    SELECT
        '总样本'::text AS loan_segment,
        serial_id,
        current_term,
        user_id,
        apply_month
    FROM eligible_terms_raw

    UNION ALL

    SELECT
        CASE
            WHEN loan_type = 'firstloan' THEN '首贷'
            WHEN loan_type = 'reloan' THEN '续贷'
        END AS loan_segment,
        serial_id,
        current_term,
        user_id,
        apply_month
    FROM eligible_terms_raw
    WHERE loan_type IN ('firstloan', 'reloan')
),
term_coupon_amount AS (
    SELECT
        e.loan_segment,
        e.serial_id,
        e.current_term,
        SUM(
            CASE
                WHEN c.type = 2 THEN COALESCE(c.coupon_amount, 0)
                ELSE 0
            END
        ) AS repayment_coupon_amt,
        SUM(
            CASE
                WHEN c.type = 3 THEN COALESCE(c.coupon_amount, 0)
                ELSE 0
            END
        ) AS interest_coupon_amt,
        SUM(
            CASE
                WHEN c.type = 4 THEN COALESCE(c.coupon_amount, 0)
                ELSE 0
            END
        ) AS quota_coupon_amt
    FROM eligible_terms e
    LEFT JOIN wangchuanliang.coupon_user_detail_copy c
      ON e.serial_id = c.serial_id
     AND e.current_term = c.current_term
    GROUP BY
        e.loan_segment,
        e.serial_id,
        e.current_term
),
coupon_monthly_count AS (
    SELECT
        e.loan_segment,
        e.apply_month,
        COUNT(
            DISTINCT CASE
                WHEN c.type = 2
                 AND c.coupon_no IS NOT NULL
                THEN e.serial_id::text || ':' || c.coupon_no
            END
        ) AS repayment_coupon_cnt,
        COUNT(
            DISTINCT CASE
                WHEN c.type = 3
                 AND c.coupon_no IS NOT NULL
                THEN e.serial_id::text || ':' || c.coupon_no
            END
        ) AS interest_coupon_cnt,
        COUNT(
            DISTINCT CASE
                WHEN c.type = 4
                 AND c.coupon_no IS NOT NULL
                THEN e.serial_id::text || ':' || c.coupon_no
            END
        ) AS quota_coupon_cnt
    FROM eligible_terms e
    LEFT JOIN wangchuanliang.coupon_user_detail_copy c
      ON e.serial_id = c.serial_id
     AND e.current_term = c.current_term
    GROUP BY
        e.loan_segment,
        e.apply_month
),
monthly_result AS (
    SELECT
        e.loan_segment,
        e.apply_month,
        COUNT(*) AS installment_cnt,
        COUNT(DISTINCT e.serial_id) AS order_cnt,
        COALESCE(SUM(a.repayment_coupon_amt), 0) AS repayment_coupon_amt,
        COALESCE(SUM(a.interest_coupon_amt), 0) AS interest_coupon_amt,
        COALESCE(SUM(a.quota_coupon_amt), 0) AS quota_coupon_amt
    FROM eligible_terms e
    LEFT JOIN term_coupon_amount a
      ON e.loan_segment = a.loan_segment
     AND e.serial_id = a.serial_id
     AND e.current_term = a.current_term
    GROUP BY
        e.loan_segment,
        e.apply_month
),
total_coupon_count AS (
    SELECT
        e.loan_segment,
        COUNT(
            DISTINCT CASE
                WHEN c.type = 2
                 AND c.coupon_no IS NOT NULL
                THEN e.serial_id::text || ':' || c.coupon_no
            END
        ) AS repayment_coupon_cnt,
        COUNT(
            DISTINCT CASE
                WHEN c.type = 3
                 AND c.coupon_no IS NOT NULL
                THEN e.serial_id::text || ':' || c.coupon_no
            END
        ) AS interest_coupon_cnt,
        COUNT(
            DISTINCT CASE
                WHEN c.type = 4
                 AND c.coupon_no IS NOT NULL
                THEN e.serial_id::text || ':' || c.coupon_no
            END
        ) AS quota_coupon_cnt
    FROM eligible_terms e
    LEFT JOIN wangchuanliang.coupon_user_detail_copy c
      ON e.serial_id = c.serial_id
     AND e.current_term = c.current_term
    GROUP BY e.loan_segment
),
total_result AS (
    SELECT
        e.loan_segment,
        COUNT(*) AS installment_cnt,
        COUNT(DISTINCT e.serial_id) AS order_cnt,
        COALESCE(SUM(a.repayment_coupon_amt), 0) AS repayment_coupon_amt,
        COALESCE(SUM(a.interest_coupon_amt), 0) AS interest_coupon_amt,
        COALESCE(SUM(a.quota_coupon_amt), 0) AS quota_coupon_amt
    FROM eligible_terms e
    LEFT JOIN term_coupon_amount a
      ON e.loan_segment = a.loan_segment
     AND e.serial_id = a.serial_id
     AND e.current_term = a.current_term
    GROUP BY e.loan_segment
)
SELECT
    t.loan_segment,
    '总计'::text AS apply_month,
    t.installment_cnt,
    t.order_cnt,
    c.repayment_coupon_cnt,
    t.repayment_coupon_amt,
    c.interest_coupon_cnt,
    t.interest_coupon_amt,
    c.quota_coupon_cnt,
    t.quota_coupon_amt
FROM total_result t
INNER JOIN total_coupon_count c
  ON t.loan_segment = c.loan_segment

UNION ALL

SELECT
    m.loan_segment,
    m.apply_month,
    m.installment_cnt,
    m.order_cnt,
    c.repayment_coupon_cnt,
    m.repayment_coupon_amt,
    c.interest_coupon_cnt,
    m.interest_coupon_amt,
    c.quota_coupon_cnt,
    m.quota_coupon_amt
FROM monthly_result m
INNER JOIN coupon_monthly_count c
  ON m.loan_segment = c.loan_segment
 AND m.apply_month = c.apply_month
ORDER BY
    CASE loan_segment
        WHEN '总样本' THEN 1
        WHEN '首贷' THEN 2
        WHEN '续贷' THEN 3
        ELSE 4
    END,
    CASE WHEN apply_month = '总计' THEN 0 ELSE 1 END,
    apply_month;
本说明仅定义分期订单红包使用统计口径；实际结果取决于查询执行时源表的最新数据。
