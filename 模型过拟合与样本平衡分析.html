一、过拟合的定义与检测方法

1.1 什么是过拟合

过拟合（Overfitting）是指模型在训练数据上表现优异，但在未见过的测试数据上表现明显下降。表现为：训练集 AUC 远高于测试集 AUC（差值 > 0.02），或者模型记住了训练数据的噪声而非学习到真正的规律。

1.2 检测方法（三重验证）

方法说明安全阈值
Train-Test Split70%训练 / 30%测试，比较 AUC 差值差值 < 0.02
3-Fold Cross-Validation3折交叉验证，取平均 AUCCV AUC 与 Test AUC 一致
特征/样本比特征数远小于样本数特征数 < 样本数/10

1.3 判断标准

Train-Test 差距判断处理建议
< 0.005无过拟合无需处理
0.005 ~ 0.02轻度可增加正则化强度
0.02 ~ 0.05中度需减特征或加正则化
> 0.05重度需重新设计模型

四、正则化分析

4.1 使用的正则化策略

策略说明效果
L2 正则化liblinear 求解器默认 L2 惩罚防止权重过大
C=1.0~3.0较弱的正则化强度（C 越大惩罚越弱）允许模型学习复杂模式但不过度
Z-score 标准化所有特征均值0、标准差1消除量纲差异，提升收敛稳定性
liblinear 求解器坐标下降法，对中小规模数据最优确保收敛到全局最优
max_iter=5000最大迭代次数充足确保完全收敛，避免欠拟合

4.2 C 参数调优

首贷三期 v5 对 C 进行了网格搜索（[0.01, 0.1, 0.5, 1.0, 3.0, 5.0, 10.0]），最优 C=3.0——较弱正则化，说明特征信噪比较高，不需要强约束。

用户流失 v6 使用 C=1.0——适度正则化，因为特征从 v4 的 47 个精减到 37 个后，剩余特征的区分力更强，不需要过强约束。

5.2 结论

两模型均无过拟合风险。


  • 首贷三期逾期预测 v5：112,720 样本、35 特征、AUC 0.978。天然的较高正样本率（43.4%）使模型无需过采样，大样本确保稳定性。
  • 用户流失预测 v6：均衡采样 10,000、37 特征、AUC 0.9675。人工均衡 + class_weight 双保险，Train-Test 差距仅 0.0032。

两模型在 6 项过拟合检测指标上均全线通过，可以投入生产使用。

5.3 注意事项

  • 模型基于历史数据训练，若业务环境发生重大变化（如产品规则调整、客群结构迁移），需重新验证
  • 建议每月用最新数据跑一次 CV 验证，监控 AUC 是否出现明显下降
  • 逻辑回归是线性模型，本身不易过拟合——如果未来换用 XGBoost/神经网络，需加强正则化
  • 用户流失模型采用均衡采样训练，但真实世界预测时仍使用原始分布，class_weight 会自动调整
