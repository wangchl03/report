02

时间锚点与统计窗口

标识定义
A 与 DA为本次固定统计截止时刻，D为A在America/Belize对应的业务日期。全部模块使用同一个A和同一批源数据快照。
T 与 OT为截至A第一次实际循环贷提单时间，按apply_time、serial_id升序定位；O为该订单。O可以未成功放款。
唯一成功放款截至A唯一循环贷成功放款订单仅用于人群准入，不替代首次实际提单订单O。
P在T之前已经成功放款的全部产品订单中，按remit_time、apply_time、serial_id降序取最后一笔。要求remit_time严格小于T。
L后窗内通过且20秒去重后的最后一笔循环贷获额代表记录，按获额时间、serial_id降序确定。
C 与 MC(P)、C(O)、C(L)分别为相应订单或获额记录按统一额度规则选出的额度；M前为前窗通过获额代表记录中已匹配提单的事件数。

前后窗口

窗口时间边界
首次提单及之前通过获额的事件时间不晚于T。前窗提单匹配和历史间隔也只使用截至T已发生的订单。
首次提单之后通过获额事件时间严格晚于T，并且严格早于A。
提单前一天行为T对应业务日期的前一天00:00至T对应业务日期00:00，左闭右开。该窗口为前一自然日。

T和P先根据真实订单确定，再关联is_pass1=1的获额。若关联不到，不改选更晚的循环贷提单或更早的成功放款订单；相应获额属性记NULL并保留关联异常。

O及P关联原始获额时使用user_id加serial_id，并要求获额时间不晚于该订单提单时间。O的金额、产品选择和额度信息不由20秒去重代表记录覆盖。

03

通过获额去重与产品识别

20秒相邻链去重

第一步筛选循环贷获额且is_pass1=1；第二步按T切分前窗和后窗；第三步在各窗口内按用户、获额时间、serial_id排序。相邻记录时间差不超过20秒即归为一批，超过20秒则开始新批次。

每批取时间最晚的一条记录；同一时刻取最大serial_id。单产品、双产品计数及提单匹配都使用该代表记录。失败获额不计数、不提供属性，也不能连接两条通过获额形成20秒链。

情况统计结果
通过记录在0秒 20秒 40秒三条相邻间隔均不超过20秒，同一窗口内合并为一批，保留40秒记录。
通过0秒 失败15秒 通过30秒先排除失败记录，两条通过记录相差30秒，形成两批。
T前5秒与T后5秒各一条通过记录T处截断链，前后窗口各记一次。前后计数相加不要求等于全历史一次去重的计数。

单产品与双产品

对代表获额的risk_product按逗号拆分，去除首尾空白、空编号及重复编号。不同编号为1个时归单产品，2个时归双产品，3个及以上保留为多产品，缺失保留为未知。多产品和未知不纳入单双产品计数，但仍可包含在通过获额总数中。

实际选择与可选供给

是否双产品提单按O原始关联的通过获额判定。是否长账期只在同次双产品获额有两个不同期限、且所选产品可准确匹配时判断：选择较长期限记1，选择较短期限记0。单产品、同期限或信息不足记NULL。

后窗L的最长可选账期取其同次可选产品期限的最大值；最低与最高息费取同次可选产品的配置总息费率total_fee。产品编号无法完整可靠匹配时，相关期限或费率记NULL并记录异常，不用剩余产品拼成不完整的报价范围。

05

提单放款次数与前窗获额选择

用户提单放款次数

F01整数

用户总提单次数

截至A，全部产品实际提单订单数，按user_id与serial_id去重；包括失败、取消和未放款订单。

F02整数

用户总放款次数

截至A，全部产品成功放款订单数；is_remit=1、remit_amt>0，放款时间有效、已发生且不早于提单时间。

F03整数

用户循环贷提单次数

截至A，recycle_type=2的实际提单订单数；不要求成功放款，不做获额20秒去重。

F04整数

用户循环贷放款次数

截至A，recycle_type=2的成功放款订单数。入选用户该字段必须等于1。

首次循环贷提单及之前的获额订单

F05整数

用户有效循环贷获额笔数（20秒去重）

先取is_pass1=1的循环贷获额，再取获额时间不晚于T的前窗记录，按窗内20秒相邻链去重后的事件数，记N前。

F06整数

有效单产品获额笔数

前窗去重代表记录中，risk_product清洗后不同产品编号恰好为1的事件数。

F07整数

有效双产品获额笔数

前窗去重代表记录中，不同产品编号恰好为2的事件数；3个及以上或缺失不计入本项。

F08小数

用户循环贷提单率

前窗代表获额按user_id加serial_id匹配到截至T已实际提单的循环贷订单的事件数M前，除以N前。只匹配代表记录；N前为0则NULL。

F090或1

用户是否双产品提单

按O原始user_id加serial_id关联通过获额。不同可选产品恰好2个记1，恰好1个记0，缺失或超过2个记NULL。

F100或1

用户提单是否长账期

按O对应通过获额的同次双产品报价比较期限。实际所选产品期限较长记1，较短记0；单产品、同期限、所选产品不在报价中或信息不足记NULL。

前窗循环贷提单率的分母仅为通过且20秒去重后的循环贷获额数。分子仅计代表serial_id已匹配截至T实际提单的事件，不要求订单放款，不以批内其他serial_id替代，不使用T之后的提单回填。

06

首次循环贷提单及之前的额度条件

本组比较首次实际循环贷提单订单O与其之前已成功放款的订单P。额度、期限、产品和费率均只关联通过获额。金额变化与比例变化分别保存。

F11数值

循环贷前一笔放款订单获额额度

取P原始订单对应的通过获额，按其vir_date及recycle_type选择额度，记C(P)。P来自全部产品，不限定循环贷。

F12数值

循环贷订单获额额度

取首次循环贷提单订单O原始关联的通过获额，按vir_date选择额度，记C(O)。不以20秒代表记录或唯一成功放款订单替换O。

F13数值

额度变化

额度变化金额等于C(O)减C(P)。正数表示提高，负数表示降低；任一额度缺失则NULL。

F14小数

额度变化幅度

额度变化幅度等于C(O)减C(P)后除以C(P)。C(P)非正或任一额度缺失则NULL；保存为小数。

F15小数

循环贷前一笔放款订单额度使用率

P的apply_amt除以C(P)。仅C(P)>0时计算；无P、额度缺失或非正时为NULL，结果不封顶。

F16小数

循环贷订单额度使用率

O的apply_amt除以C(O)。仅C(O)>0时计算；额度缺失或非正时为NULL，结果不封顶。

F17整数天

循环贷前一笔放款订单天数

取P实际选择产品对应的完整借款期限天数。没有P、通过获额无法关联或期限无法确定时为NULL。

F18整数天

循环贷订单天数

取O实际选择产品对应的完整借款期限天数。该字段表示产品账期，不表示距离今天的天数。

F19小数

循环贷前一笔放款订单息费

取P实际选择产品对应的产品配置总息费率total_fee，按小数保存；无P或对应信息无法可靠关联时为NULL。

F20小数

循环贷订单息费

取O实际选择产品对应的产品配置总息费率total_fee，按小数保存。与前一笔使用同一口径。

用户总事件次数

首次循环贷提单前一自然日内，已可靠关联到该用户的有效埋点事件记录总次数。真实无事件为0，用户或数据覆盖无法核实时为NULL。

同一行为窗口内，修改金额及切换金额所对应埋点事件的合计次数。按实际事件字典映射，单条记录不重复计数。

F25整数

切换期次次数

同一行为窗口内，切换期次选项所对应埋点事件次数。真实无该事件为0，无法可靠关联时为NULL。

F26整数

看还款计划次数

同一行为窗口内，查看还款计划所对应埋点事件次数。真实无该事件为0，无法可靠关联时为NULL。

使用wangchuanliang.user_behavior_data_record时，实际事件时间采用毫秒时间戳event_time，转换为America/Belize业务时间。通过sequence_id与用户表关联得到user_id；create_time不替代实际事件时间。

sequence_id为空、仅含空白、未匹配用户或匹配多个用户时记录关联异常，不能据此填写“无行为”。只有数据覆盖正常、用户映射可靠且窗口内确实无事件时，次数才记0。行为事件按有效记录计数；同一事件同时命中多个配置时只计一次。

先取is_pass1=1的循环贷获额，再取T之后且A之前的后窗记录，按窗内20秒相邻链去重后的事件数。

F28整数

有效单产品获额笔数

后窗去重代表记录中，不同可选产品编号恰好为1的事件数。

F29整数

有效双产品获额笔数

F30数值

循环贷订单获额额度

取后窗最后一笔通过且去重后的循环贷获额代表记录L，按L自身vir_date选择额度，记C(L)。不存在L则NULL。

F31数值

额度变化

F34小数

取L同一次通过获额中可选产品配置total_fee的最低值，按小数保存；不跨多次获额取历史极值。

获额订单最高息费

取L同一次通过获额中可选产品配置total_fee的最高值，按小数保存；单产品时与最低息费相同。

F36整数天

第一笔循环贷获额通过距离今天天数

在后窗通过且去重后的循环贷获额集合中取最早代表记录，统计日D减该记录的Belize获额日期。不存在则NULL。

F37整数天

最后一笔循环贷获额通过距离今天天数

在同一后窗集合中取最晚代表记录L，统计日D减L的Belize获额日期。不存在则NULL。

09

空值规则与取值核对

场景取值规则
窗口内确实没有符合条件获额对应获额次数为0。没有L时后续额度、期限、息费、变化及距今天数为NULL。
没有前序成功放款订单PP的额度、使用率、期限和息费为NULL；相对P的额度变化金额与幅度为NULL。
额度分母非正或缺失使用率为NULL；变化幅度基准非正或缺失时为NULL。原始订单保留。
事件或产品关联无法确认相关属性为NULL并记录异常，不按0填充，不任取一条冲突数据。
关键源键或历史记录冲突按用户保留质量排除审计，避免删除一笔异常循环贷放款后误判为恰好1笔。
无实际行为与数据缺失覆盖正常且真实无事件为0；无法核实数据覆盖或用户归属为NULL。
