四、变化一：t1_ovd 系数暴涨

+11.18 → +21.32（+90.7%），排名 #1 → #1（不变）

t1_ovd 从头号特征变成了"超级头号特征"——它的权重几乎翻倍。这不是因为它变得"更擅长预测"了，而是其他特征的信号崩塌后，L2 正则化迫使它吸收了原有的份额。

4.1 核心逻辑：L2 正则化的"信号重新分配"效应

理解这个变化需要理解 LogisticRegression + L2（C=1.0）的优化机制：

  • L2 正则化的惩罚项是 λ × Σ(系数²)，意味着它始终倾向于让所有系数"尽量小"。但如果某个特征信号极强，优化器会接受给它一个较大的系数，以换取其他特征系数的缩小——因为总惩罚 = 拟合误差 + λΣ(coef²)，一个特征的贡献替代多个特征可以降低总惩罚。
  • 在 v6 中，12 个页面行为特征（np、ad、cf、am 等）合计贡献了约 5.5% 的预测信号。它们通过 L2 正则化"分摊"了部分总系数权重，使得每个特征都有适中的系数。
  • 在 v8 训练数据中，这 12 个页面行为特征的有效覆盖率从 100% 骤降至 14%（71,645 人中仅约 10,000 人有真实 event_track 值，另外 61,645 人为 0-填充）。L2 正则化会检测到这些特征的"有效方差"极低（绝大多数样本值为 0），从而将它们的系数大幅压缩。
  • 这些被压缩掉的"信号份额"并不会凭空消失——L2 正则化的总惩罚压力迫使优化器将它们重新分配给仍然有强信号的特征。t1_ovd，作为唯一覆盖 100% 用户、且与标签相关性最强的特征，成为了这些份额的"接盘侠"。
🎯 足球比喻：v6 有 12 个中场球员（页面行为特征）帮助控球，前锋 t1_ovd 只需要完成最后一击。v8 只有 1.4 个中场（14% 覆盖率），t1_ovd 不得不回撤到中场拿球、组织进攻、再冲刺射门——它的"工作量"翻倍了，所以权重翻倍了。

4.2 第二个因素：has_prior_reject 的间接推动

新增特征 has_prior_reject 也对 t1_ovd 的权重产生了间接推动作用：

  • has_prior_reject 捕获了"用户是否有被拒经历"这一信号，该信号与页面行为特征高度重叠（被拒用户浏览更多、进入提单页更多）。
  • 当 has_prior_reject 吸收了这个重叠信号后，页面行为特征的残余信号进一步减弱 → L2 进一步压缩它们 → 更多权重流向 t1_ovd。
  • 同时，has_prior_reject 解释了部分原本由 t1_ovd 间接反映的"用户质量"信息（被拒用户的 od1 均值 69.9 天 vs 未拒用户的 121.3 天），但 t1_ovd 作为连续变量比二值变量 has_prior_reject 包含更丰富的信息，所以在权重竞争中，t1_ovd 仍然胜出。
⚠ 重要提示：t1_ovd 在 v8 中的 +21.32 是一个被"通胀"了的值。如果使用完整 event_track 数据重训，这个值应回落至 +13~+15 左右。当前的高系数是数据稀疏性 + L2 正则化共同导致的"信号集中"效应，不代表 t1_ovd 的真实预测力增强了 90%。在评分卡应用中，如果直接使用这个通胀系数，t1_ovd 的评分权重将过度集中，影响评分分布的合理性。

五、变化二：页面行为三巨头 np/ad/cf 全面崩塌

np（-2.77→+0.05）、ad（-1.70→-0.12）、cf（-0.62→-0.01）——这三个在 v6 中排名 #2/#3/#5 的核心页面行为特征，在 v8 中几乎丧失了全部预测力。原因有三层：has_prior_reject 的信号替代、86% 零填充导致的 L2 压缩、以及特征间的多重共线性暴露。

5.1 np — 提单页进入次数（-2.77 → +0.05，#2 → #9）

v6 中的 np：一个优雅的"犹豫信号"

在 v6 中，np 排名 #2，系数 -2.77（负 = 保护性）。它的业务逻辑是：

  • "进入提单页很多次但最终没有提交" = 用户在犹豫、在比较、在不确认 → 这些用户实际提交后表现反而更好（因为他们是深思熟虑型借款人）。
  • 反之，"只进一次提单页就提交" = 冲动型借款人 → 逾期风险更高。
  • np 是页面行为特征中信号最强的，因为它处在"申请漏斗"的最窄处——提单页是最接近决策转化的页面。

v8 中 np 为什么崩了？

  • 第一层：has_prior_reject 捕获了"谁在犹豫"：被风控拒绝过的用户必然会多次进入提单页——他们第一次尝试被拒，第二次、第三次再尝试。has_prior_reject 直接标识了这类用户。一旦模型知道"这个用户曾被拒绝"，np 的"多次进入提单页=被拒用户=低风险"这条路径就被截断了。
  • 第二层：86% 零填充杀死了残余信号：剩下的 14% 有真实 event_track 的用户中，np 的边际预测力已经很小——has_prior_reject 已经解释了最核心的"犹豫 vs 冲动"差异。L2 正则化检测到 np 在绝大多数样本上为零，将其系数压缩至接近零。
  • 第三层：系数方向的翻转（+0.05）是噪声：np 从 -2.77 变成 +0.05，这个微弱的正系数没有统计显著性——它只是 14% 有效样本中随机噪声的反映。在完整数据上重训后，np 的系数方向应恢复为负值。

5.2 ad — 活跃天数（-1.70 → -0.12，#3 → #7）

v6 中的 ad：分散活动 = 更低风险

ad 排名 #3，系数 -1.70。用户在注册到放款窗口内，有多天（而非集中在一天）有页面行为——这意味着用户是在"从容地了解和决策"，而非"急迫地借钱"。ad 高的用户逾期风险更低。

v8 中 ad 为什么被削弱？

  • 被拒用户天然有更高的 ad：被拒用户经历了"申请→被拒→再申请→获批"的流程，这个过程天然跨越更多天。has_prior_reject 与 ad 正相关（被拒用户 ad 均值更高），当 has_prior_reject 进入模型后，ad 中"由被拒经历驱动的活跃天数"这部分信号被剥离了。
  • 剩余的"有机活跃天数"信号仍然存在但弱得多：排除了被拒用户后，非被拒用户中 ad 的变异主要来自"用户本身的决策节奏"差异——这个信号在 14% 有效覆盖率下不足以对抗 L2 压缩。
  • -0.12 仍有微弱保护信号：与 np 不同，ad 的方向没有翻转——它仍然保持为负系数，说明"活跃天数多=风险低"这个核心逻辑在完整数据上是成立的，只是当前数据下信号被严重稀释。

5.3 cf — 确认提单次数（-0.62 → -0.01，#5 → #14）

v6 中的 cf：确认提交 = 认真借款人

cf 排名 #5，系数 -0.62。进入最终确认页面的次数多 → 用户在认真阅读条款、核对信息 → 这类用户更可靠。这与 np 的逻辑互补：np 测量"犹豫"，cf 测量"认真"。

v8 中 cf 为什么归零？

  • 被拒用户也会多次进入确认页：他们尝试提交但被风控拦截，所以 cf 值也偏高。has_prior_reject 分离了"被拒驱动的确认"和"自发认真的确认"。
  • 剩下的"自发认真"信号太弱：在非被拒用户中，cf 的变异本身就很小（大多数用户只确认一次），加上 86% 零值的稀释，L2 几乎没有给它留任何空间。
  • cf 和 np 高度共线（r≈0.7+）：进入提单页次数多 → 进入确认页次数自然也多。在信号已经薄弱的 v8 数据中，L2 无法为两个高度相关的特征同时保留系数——它选择了将权重集中给其中一个（np，尚有 +0.05），另一个（cf）被清零。

5.4 am — 金额切换页次数（-0.33 → -0.01，#10 → #15）

逻辑与 np/ad/cf 一致

am（反复调整借款金额）在 v6 中是一个弱保护特征：金额调整 = 用户在谨慎考虑自己的还款能力。但在 v8 中：

  • 被拒用户可能因为额度被下调而多次进入金额页，has_prior_reject 吸收了这部分信号。
  • 剩余信号在 86% 零填充下被 L2 清零。

六、变化三：优惠券特征 cp/cc 双双清零

cp（+0.51→0.00）和 cc（+0.50→0.00）在 v6 中位列 #7 和 #8，是仅有的两个"正系数页面行为特征"——访问优惠券页面/点击优惠券 = 风险上升。但在 v8 中，两者系数均为精确零。

6.1 cp — 优惠券选择页进入次数（+0.51 → 0.00）

v6 中 cp 为什么是风险信号？

cp 的正系数（+0.51）表明：进入优惠券页面越多的用户，逾期风险越高。这背后的业务逻辑是：

  • 价格敏感型用户：花时间比较优惠券 → 说明用户在意借款成本 → 这类用户通常资金更紧张、更需要精打细算 → 逾期风险更高。
  • "找最优条件"行为：反复查看优惠券意味着用户对当前借款条件不满意，在寻找更好的方案——这本身就是资金压力的信号。
  • 注意：cp 的逻辑与 np 相反——np 是"犹豫=保护"，cp 是"找优惠=风险"。区别在于 np 反映的是"对借款本身的犹豫"（审慎），cp 反映的是"对成本的在意"（资金紧张）。

v8 中 cp 为什么被清零？

  • 数据覆盖率灾难：v8 训练数据中，仅约 10,000 用户有真实 coupon 数据（14%），其余 61,645 人为零填充。L2 正则化面对一个 86% 为零的特征，几乎没有保留系数的动力。
  • has_prior_reject 的间接影响：被拒用户最终获批后，可能更倾向于寻找优惠券（他们知道自己的借贷资质偏弱，需要降低成本）。has_prior_reject 捕获了这部分"被拒→找优惠→风险"的链条，cp 的边际信号进一步减弱。
  • cp 在 v6 中本就不算强特征：贡献度仅 0.041%，排名 #7。它本身就是"刚好能对抗 L2"的临界特征，数据覆盖率一降就立刻被清零。

6.2 cc — 优惠券点击次数（+0.50 → 0.00）

逻辑与 cp 完全同源

cc 是 cp 的"行为深化版"——不仅进入了优惠券页面，还点击了具体优惠券。在 v6 中，cc 与 cp 的系数几乎相同（+0.50 vs +0.51），说明它们捕捉的是同一个信号维度。在 v8 中，两者同归于零，原因与 cp 完全一致：数据稀疏 + L2 压缩 + has_prior_reject 替代效应。

七、变化四：t1_ahead 从 #4 跌落消失

+0.84 → 0.00，从第4重要特征到被 L2 清零

t1_ahead 是十个核心特征中唯一来自"还款行为域"但系数被清零的特征。它的消失揭示了一个反直觉的模式，也是本报告中最具业务洞察力的变化。

7.1 反直觉的 v6 系数：提前还款 = 更高风险？

系数解读：t1_ahead 的 +0.84（正 = 风险特征）

直觉上，提前还款应该是好用户的标志。但 v6 模型给出的结论是相反的——t1_ahead 越大（提前还款天数越多），逾期风险越高。这不是模型的错误，而是揭示了一个真实的行为模式：

  • "前置善意"策略：部分用户在获得首贷后立刻提前还清第1期。他们的动机不是"我有余钱所以提前还"，而是"我要尽快解锁循环贷资格"（循环贷要求"在途订单还款≥50%后再次支用"）。这些用户是"策略型借款人"——他们从一开始就计划好要循环使用额度，首贷只是敲门砖。
  • "我先表现好，然后借更多"：这是我们在循环贷双逾期分析中反复验证的模式——首贷提前还款用户中，后续双逾期（两笔同时逾期）的概率显著更高。因为他们的首贷金额通常较小（测试性质），真正暴露风险的是续贷。
  • 反之，准时还款（不提前也不逾期）：可能是更"稳定"的借款人——他们按部就班，没有急迫的资金需求，也没有快速扩张借款规模的意图。

对比 t1_on_time（-0.52 → -0.48，排名 #6 → #3）

注意：t1_on_time（准时还款标记）的系数几乎没有变化（-0.52 → -0.48）。这恰好印证了上述逻辑——准时还款 = 好用户（负系数），提前还款 = 风险用户（正系数）。两个特征测量的是不同的行为模式：

第1期还款行为t1_aheadt1_on_timet1_ovdv6 风险判断
准时还款（到期日当天或之前==0） =0 =1 =0 最低风险
提前还款（提前 N 天） >0 =0 =0 中等风险（策略型）
逾期还款（逾期 N 天） =0 =0 >0 高风险

7.2 v8 中 t1_ahead 为什么被清零？

has_prior_reject 打破了"提前还款=策略型"的关联

t1_ahead 在 v6 中的预测力依赖于一个关键相关关系：提前还款的用户中，"策略型借款人"占比高。但 has_prior_reject 的引入打破了这个关联：

  • 被拒用户获批后很少提前还款：他们知道自己的资质偏弱，已经被风控"盯上"过一次了，获批后会格外谨慎——既不逾期、也不提前（因为提前还款意味着"我在测试额度"，可能引发风控的二次关注）。被拒用户的第1期还款模式更倾向于"准时还款"。
  • 非被拒用户的提前还款才具有"策略信号"：但 has_prior_reject 已经将一个重要的用户分层维度引入模型后，t1_ahead 在剩余用户中的预测力大打折扣。
  • 数据方面：t1_ahead 本身是一个稀疏特征——绝大多数用户 t1_ahead=0（因为要么准时、要么逾期，提前还款的比例本身就低）。在 v8 中，这个稀疏特征在与 has_prior_reject 和 t1_on_time 的竞争中落败，被 L2 清零。
🔍 关键判断：t1_ahead 在 v8 中被清零，并不意味着"提前还款无信息量"。它的信号被 has_prior_reject + t1_on_time 联合覆盖了——前者解释了"谁会提前还款"，后者解释了"谁是好用户"。这实际上是一种"信号去重"：v6 中 t1_ahead 同时承载了"用户分层"和"行为模式"两个维度的信息，v8 中这两个维度被更精准的特征分别捕获。

八、总结与建议

  1. has_prior_reject 是真正的增量特征：在 v8 中排名 #2，系数约 -0.51，贡献度约 0.5%。它将"用户是否有被拒经历"这一外部信息带入模型，对 od1=0 的低风险段用户区分度尤为突出（DPD30+ 率 14.6% vs 4.7%）。该特征与 od1 相关系数仅 -0.10，提供独立于现有特征体系的增量信息。
  2. t1_ovd 的权重膨胀是"信号集中"现象，非真实预测力增强：当前 +21.32 的系数中，约 40%~50% 是从被 L2 压缩的页面行为/优惠券特征处"继承"来的。在完整数据上重训后，预期 t1_ovd 系数将回落至 +13~+15 区间。评分卡设计时需注意这一效应。
  3. 页面行为特征（np/ad/cf/am）需要完整 event_track 数据才能展现真实重要性：当前 14% 的有效覆盖率严重低估了它们的贡献。v6 中页面行为合计贡献 5.5%，这是一个可信的基线。如果 v8 无法获取完整 event_track 数据，建议至少确保 np 和 ad 有足够覆盖率——它们是页面行为域信号最强的两个特征。
  4. 优惠券特征（cp/cc）在 v6 中已是临界特征，v8 数据稀疏彻底宣告它们出局：在完整数据上 cp 可能恢复至 +0.15~+0.30，但 cc 与 cp 高度共线，建议在 v9 中考虑将两者合并（如 cp+cc 或取 max）。
  5. t1_ahead 的信号已被 has_prior_reject + t1_on_time 联合覆盖：不建议强行恢复 t1_ahead——它在 v8 的特征体系中已是冗余信息。如果未来需要捕捉"策略型借款人"，可以考虑构建一个更直接的"首贷-续贷时间间隔"特征。
  6. 核心建议：请务必在完整 event_track + coupon 数据上重新训练 v8 模型。当前 v8 的系数估计受数据覆盖率偏差影响，方向正确但幅度不可靠。完整数据训练后才能确定：（a）页面行为特征的真实权重，（b）t1_ovd 的真实系数水平，（c）优惠券特征是否值得保留。预计完整数据训练后 AUC 将恢复至 0.960+ 水平。
