口径

口径说明
样本order_loan_f_v2_copy。loan_type = reloan，total_term = 1，product_no 为 100741 或 100742。is_remit = 1 且 remit_amt > 0。
到期due_date 在 2026-01-01 至 2026-09-30，且 due_date > 2000-01-01，due_date < 2026-10-13。数据日 2026-10-13。
逾期率loan_status_code = 8 的订单数 / 该产品到期订单数。按数据日的当前状态，不截在到期日。
盈利率Σ(repaid_amt − remit_amt) / Σremit_amt。repaid_amt 为当前累计还款，不截在到期日。
息费前置 = Σpre_amt / Σremit_amt。后置 = Σpost_amt / Σremit_amt。总息费 = Σ(pre_amt + post_amt) / Σremit_amt。砍头息指 pre_amt > 0。
410 分model_result_copy.serial_id = 放款订单 serial_id，字段 kabybmerge410fpd7cre。分值 > 0 为有效分。两款覆盖率均为 100%。分越高，资质越好。
用户分同一产品、同一用户多笔放款，取 due_date 最晚、serial_id 最大的一笔。人数分组按该分数从高到低，(行号 − 1) / 人数。前 20% 为 < 0.20，20%–50% 为 < 0.50，其余为后 50%。
异动样本仅 100742，到期月 2026-06 至 2026-09。低分线 464 是该产品 1–9 月到期订单的分数中位数。中间段为 [464, 492)，高分段为 ≥ 492。492 是该产品订单分数前 20% 的下沿。
结构对照9 月各段放款金额权重，乘以 7 月各段当前盈利率，得到约 18.5%。与 7 月 20.61% 的差约为结构影响，与 9 月实际 3.25% 的差为各段内部变化。
14 天窗口还款取 repayment_record_copy 中 payin_date ≤ due_date + 14 的金额。9 月只保留 due_date ≤ 2026-09-29 的订单，使 7、8、9 月都观察满 14 天。盈利率仍是这段还款合计减去放款，再除以放款。
汇总 SQL 
SET search_path TO wangchuanliang, public;

SELECT product_no::text,
       COUNT(*) AS n,
       COUNT(DISTINCT user_id) AS n_user,
       ROUND(AVG(remit_amt)::numeric, 0) AS avg_remit,
       SUM(CASE WHEN loan_status_code = 8 THEN 1 ELSE 0 END) AS n_od,
       ROUND(100.0 * SUM(CASE WHEN loan_status_code = 8 THEN 1 ELSE 0 END) / COUNT(*), 2) AS od_pct,
       ROUND(100.0 * (SUM(COALESCE(repaid_amt,0)) - SUM(remit_amt)) / SUM(remit_amt), 2) AS profit_pct,
       ROUND(100.0 * SUM(COALESCE(pre_amt,0)) / SUM(remit_amt), 2) AS pre_pct,
       ROUND(100.0 * SUM(COALESCE(post_amt,0)) / SUM(remit_amt), 2) AS post_pct,
       ROUND(100.0 * SUM(COALESCE(pre_amt,0) + COALESCE(post_amt,0)) / SUM(remit_amt), 2) AS fee_pct,
       SUM(CASE WHEN COALESCE(pre_amt,0) > 0 THEN 1 ELSE 0 END) AS n_pre
FROM order_loan_f_v2_copy
WHERE loan_type = 'reloan'
  AND is_remit = 1
  AND COALESCE(remit_amt, 0) > 0
  AND total_term = 1
  AND product_no IN (100741, 100742)
  AND due_date > DATE '2000-01-01'
  AND due_date < DATE '2026-10-13'
  AND due_date >= DATE '2026-01-01'
  AND due_date < DATE '2026-10-01'
GROUP BY 1;

-- 410 分：model_result_copy.kabybmerge410fpd7cre > 0，按 serial_id 关联。
-- 用户分组在产品内按分数降序，(row_number - 1) / n。

源表 order_loan_f_v2_copy、model_result_copy。金额为墨西哥比索原币。数据日 2026-10-13。
